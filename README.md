# fusion-story-director-studio v7.0

爆款经典故事开发 **×** AI 导演工作室融合系统，装进 Claude Code。把创意策划、编剧、剧本医生、台词编辑、导演总控、场面调度、叙事构图、武术指导、分镜设计、AI 生成策划、剪辑声音设计和项目管理串成一条**从一句话创意到成片验收**的全链路。

```
skills/fusion-story-director-studio/
  SKILL.md                          主控：五层架构、A–Q 路由、21 引擎、质量门
  references/
    经典对白机制库_V4.md            按需加载：中文台词，272 机制＋56 语域变体＋132 声纹
    美剧对白机制库_EN-V1.md         按需加载：英文台词，84 机制＋16 类语域＋27 声纹原型
    美式质感库_US-V1.md             按需加载：美国背景，中式逻辑排查＋制度装置＋物理线索
```

**总策略：先爆款，后心因，再经典化。** 故事层让人想看，心因层让人上头，符号层让人忘不掉。

**创作裁决优先级**（冲突时按此排序）：
> 人物真实 > 叙事清晰 > 因果与设定自洽 > 观众认知 > 镜头连续 > 动作因果 > 情绪强度 > 执行可行 > 视觉美感 > 传播噱头。

- **第〇部分 主控层**：身份边界、10 条铁律、运行控制（配置变量 / 输入成熟度 L0–L4 / 提问策略 / 输出深度与分段 / 单一事实源）、能力真实性、快捷指令。每次任务必读。
- **第一部分 任务路由**：A–R 共 18 条路径＋路由优先级＋关键边界。每轮只选一个主路径，不因出现某个关键词就自动扩张成全流程。

- **第三部分 结构骨架库**：A 钩子升级反转 / B 三番包袱 / C 日常裂缝余味 / D 起承转合 / E 三幕式 / F 栏目化连载 / G 心因单元。先选型后加载，禁止默认三幕，可分层嵌套。
- **第四部分 专项引擎库**：22 个引擎，被路由或任务引用时展开。
- **第五部分 质量门与交付**：G0–G11 质量门（四态判定）、存档卡三档、修改协议、分层自检、启动模板。

## 核心：角色心因驱动（引擎 13）

把角色写成观众的情绪开关，而不是让剧情拖着角色走：

- **四缺**：缺点（惹麻烦的性格）· 缺失（生命里少掉的东西）· 缺憾（过不去的旧债）· 缺陷（现实硬限制）——且必须有**社会集体性**，观众看到的不是角色，是自己。
- **三心因三事件**：先定目标角色与三次心因变化（撼动 → 逼迫 → 选择），再反推三个事件；事件像手指，按在角色缺口上。
- **替代成长**：外部成果必须沉淀为内在获得（王位 → 掌控感、洗冤 → 尊严恢复）；受众不是年龄段，是心理需求群体。
- 配套模板：【角色心因卡】【三事件三心因设计表】【篇章开发表】【心因自检】。

## 经典对白机制库 V4（引擎 6 外挂）

治 AI 写中文台词的三大病——**死板**（每句完整正确但不像人话）、**翻译腔**（句子工整像字幕、情绪激烈时说排比长句）、**逻辑不顺**（不回应上一拍、答没人问的问题、陌生人跳过警惕直接交换信息）。

从 26 部（组）高传播度作品蒸馏：国产 14 部（《大明王朝1566》《潜伏》《我爱我家》《武林外传》《让子弹飞》《甄嬛传》《狂飙》《亮剑》《琅琊榜》《漫长的季节》等＋周星驰四部、《无间道》＋杜琪峰、话剧《茶馆》）＋日韩 6 部（《请回答1988》《半泽直树》《Legal High》《白色巨塔》、是枝裕和、《寄生虫》《我的大叔》）＋动漫 4 部（《银魂》《化物语》《灌篮高手》《海贼王》）。

每个机制五段式：说明／经典锚点（≤2 句原文＋出处）／生效原理／适用场景／❌病句→✅正句对照（原创示范）。例：

> **答非所问** — 被问到不能答的问题，不接话茬，直接说眼前琐事，回避本身就是回答。
> ❌「我不想回答这个问题，请你不要再问了。」 → ✅「——今天这馒头碱放少了。」（低头掰馒头）

**用法**：写台词前按场景反查机制编号（库内第六部分 26 类场景速查），改稿时先定位缺哪个机制再动笔，不凭感觉润色。学的是机制不是句子——锚点只作校准，禁止把原文当金句抄进正文。

## 美剧对白机制库 EN-V1（引擎 6 外挂，英文创作专用）

中文库治的是称谓、面子、台阶、含蓄；**英文没有这套装置**，所以这不是翻译，是另建一套。英文对白靠 status transaction（地位交易）、turn-taking（回合争夺）、deflection（回避）、register（语域）、comedy architecture（喜剧结构）运行。

治英文对白七大病：回合太整齐／人人客气平等／把心里话说出来（on-the-nose）／句子都一样长且语法完整／人人一个声音／笑点飘没结构／行话像百科。

84 个机制分八类——回合与反应（抢话重叠、迟半拍、答错问题、沉默当回合）／地位与权力（假征询真命令、谢字当刀、谁结束场面、打断权分配）／潜台词与回避（转移到物、拒绝命名、谈未来避现在）／节奏与句法（碎句、压力下一句到底、三拍律、写进停顿）／声音差异化（句长指纹、回避方式指纹、缺席的词）／喜剧机制（setup-runner-callback、认真对待荒唐、button）／类型语域 16 类（程序剧速记、法律限定、军事被动、犯罪委婉语、学术、宗教、体育、交易大厅、军法、教育、销售、窗口办事）／结构性台词（cold open、act break、runner、tag、晚进早出）。

另附 **27 个声纹原型**（V1–V27）：操盘手、体制人、笑面刀、继承者、老狮子、能手、解释者、耗尽者、信徒、犬儒、转移者、管家型、伤口、表演者、缺席的父母、委婉者、话痨打手、沉默的肌肉、清道夫、正经人、加码者、浑然不觉、用力过猛、过度具体者、玩笑防御、提前原谅者、拒绝命名者——每个给全六维指纹，直接填进 EN 声纹卡即可用。硬规则：**同一部戏里主要角色的「回避方式」必须两两不同**，这一维最容易撞车也最致命。

**两库选用**：写中文用 V4；写英文用 EN-V1；写中文但想借美剧手艺，查 EN-V1 每部分末尾的【中文转译】。

> ⚠️ **可靠性差异**：V4 的锚点是逐集听打台词本的逐字引文并注明出处；**EN-V1 没有逐字锚点**——其"情境锚点"是技法的描述性复述，可用于设计与改稿，**不可用作引用来源**。这是刻意的诚实边界，不是遗漏：凭记忆写引文必然出错，而引文正是最不能糊弄的地方。

## IP 改编还原度（引擎 22）与弹幕预演（引擎 3）

**观众在弹幕里聊的是剧情、人物、爽点、还原度**，不是画面技术。这两块直接对着观众真实反应设计。

### 还原的是观众的记忆，不是原著的文字

观众说「还原」时指的是：人物没崩、名场面在、情绪体验对、关系没变味、爽点兑现了。所以**逐字照搬也可能被骂魔改**——小说的内心戏搬上屏幕就是死的，观众感受到的是「人物变木了」。

还原度四层，改编前先分层写进存档卡：

| 层 | 内容 | 处置 |
|---|---|---|
| **L1 不可动** | 人物核心行为逻辑、关系本质、名场面的情绪功能、结局情绪方向、硬设定 | 动了就是魔改 |
| **L2 可重构不可丢** | 情节顺序、场景合并、支线压缩、配角合并 | 改形式可以，功能必须落到别处并记录去向 |
| **L3 必须改** | 内心独白、叙述性设定、群像视点、超长时间线 | **不改是失职**——外化是改编的最低义务 |
| **L4 可原创** | 过渡戏、生活质感、次要冲突形态 | 自由，但不得抢主线 |

分层争议时：**读者记忆强度 > 原著篇幅 > 作者偏好**。写了三章但没人记得的是 L2；写了三行但被反复二创的是 L1。

另含：原著资产盘点表（名场面／名台词／爽点账本／硬设定／争议点）、**七条魔改红线**（按被骂强度排序，第一条是「人物行为不符合原著逻辑」）、媒介必要改动对照表（每项须记录「保住了原著的什么功能」，写不出就是魔改）、原著党与新观众双轨设计、三档改编方案。

### 弹幕预演（场面级诊断）

每写完一场戏预演：**观众会刷什么？** 写不出来就说明这场没功能。八类弹幕各有诊断含义——

爽点兑现／情绪／人物／预测考据／玩梗二创 = 健康；**吐槽**（"编剧脑子进水"）= 逻辑漏洞或人物崩；**"原著不是这样的"** = 走引擎 22.7 回查；**空白** = 最危险，这场删、并或重写。

> 与引擎 13 的关系：弹幕是**替代成长的即时读数**。观众刷「这就是我」说明四缺的社会集体性击中了；只刷「好帅」不刷「这就是我」，说明角色是奇观不是入口。

## 美式质感库 US-V1（美国背景项目必查）

**与语言无关**——即使全片中文、面向中文观众的「美式短剧」，只要故事发生在美国就适用。它管的不是句子，是**这个故事和这个画面是不是真的发生在美国**。

核心是第一部分 **20 条中式逻辑泄漏排查**：AI 做的美剧不像，八成不是台词问题，是中式戏剧逻辑穿了美国衣服——

| 泄漏 | 为什么不成立 | 改法 |
|---|---|---|
| 给台阶推动和解 | 美式冲突要么当面说完，要么彻底不谈，没有中间仪式 | 逼两人当面说，或关系永久降级 |
| 面子当行为动机 | 美国人怕的是制度后果，不是别人怎么看 | 换成丢工作、失监护权、信用记录、被起诉 |
| 长辈权威不可顶撞 | 美式家庭剧默认子女当面顶撞，这是常态不是事件 | 权威换成筹码——钱、遗产、探视权、医疗决定权 |
| 围观群众做道德审判 | 美式审判由制度或网络执行，陌生人默认不介入 | 换成 HR、警察、律师、有人录了视频发上网 |
| 忍耐当美德 | 美式叙事把长期忍耐读作病态或懦弱，不是德行 | 主角必须**早就说过**，只是没人听——憋屈来自发声无效 |
| 打脸靠当众羞辱 | 美式复仇的爽点在制度性毁灭 | 一纸传票比一场大闹更狠，也更美式 |

另含 **18 个会自己长出剧情的美式制度装置**（医疗账单、学贷、信用分、HR、诉讼威胁、监护权、假释、移民身份——同时是美国观众的社会集体四缺，可直接喂给引擎 1 与 13）／12 条行为语法／6 大地域质感／8 项阶级标记（**美式阶级靠教育与品味显形，不靠豪宅名车**——牙齿、大学、时间自主权比收入更能定位一个人）／6 条情绪语法（**美式默认愤怒外化、悲伤内化，与中式相反**）／AI 生成的美式物理线索与 10 条常见错误（双黄线、木电线杆、纱窗、扁脚插座、strip mall、地域混搭）。

> ⚠️ 第二、六部分是可核查事实，可直接采信；第一、三、五、八部分是文化倾向的概括，**用作排查清单（发现可疑处→改），不用作生成模板（照着套→刻板印象）**。

## 用法

系统按动作词和交付对象自动路由，不需要你记路径名：

| 你想要 | 可以这样说 |
|---|---|
| 审剧本，先别改 | 「审一下这个剧本」 |
| 改台词（中文） | 「把台词改得像人话」 |
| 改台词（英文） | 「fix this dialogue, it's on-the-nose」 |
| 想点子 / 选题 | 「帮我想几个方向」 |
| 一句话创意扩成设定 | 「把这个概念扩成世界观和角色设定」 |
| 角色立不住、剧情不上头 | 「帮我把这段戏改成心因驱动」 |
| 打斗 / 动作分镜 | 「按顶级武指标准做这场动作分镜」 |
| 只要生成 Prompt | 「已有分镜，只要视频 Prompt」 |
| 参考图动起来 | 「这张图怎么动，给四种方案」 |
| 导演阐述 / 怎么演 | 「从导演角度说这场怎么导」 |
| 多集短剧 | 「拆成 X 集，每集 Y 秒」 |
| 完整执行包 | 「从剧本到成片的完整执行包」 |

**快捷指令**：`路径X` / `深度：精简·标准·全量·导演执行` / `只要 Prompt` / `继续` / `保存卡片` / `红队` / `锁定：……` / `禁止：……` / `假设继续`。
