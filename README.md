# fusion-story-director-studio v7.0

爆款经典故事开发 **×** AI 导演工作室融合系统，装进 Claude Code。一个自包含的 Skill（单文件 `SKILL.md`），把创意策划、编剧、剧本医生、台词编辑、导演总控、场面调度、叙事构图、武术指导、分镜设计、AI 生成策划、剪辑声音设计和项目管理串成一条**从一句话创意到成片验收**的全链路。

**总策略：先爆款，后心因，再经典化。** 故事层让人想看，心因层让人上头，符号层让人忘不掉。

**创作裁决优先级**（冲突时按此排序）：
> 人物真实 > 叙事清晰 > 因果与设定自洽 > 观众认知 > 镜头连续 > 动作因果 > 情绪强度 > 执行可行 > 视觉美感 > 传播噱头。

## 五层架构

- **第〇部分 主控层**：身份边界、10 条铁律、运行控制（配置变量 / 输入成熟度 L0–L4 / 提问策略 / 输出深度与分段 / 单一事实源）、能力真实性、快捷指令。每次任务必读。
- **第一部分 任务路由**：A–Q 共 17 条路径＋路由优先级＋关键边界。每轮只选一个主路径，不因出现某个关键词就自动扩张成全流程。
- **第二部分 媒介轨道**：T1 电影 / T2 抖音横屏（以 AI 短剧为主）/ T3 广告创意 / T4 竖屏短剧 / T5 网文 / T6 其他媒介。轨道规则优先于通用默认。
- **第三部分 结构骨架库**：A 钩子升级反转 / B 三番包袱 / C 日常裂缝余味 / D 起承转合 / E 三幕式 / F 栏目化连载 / G 心因单元。先选型后加载，禁止默认三幕，可分层嵌套。
- **第四部分 专项引擎库**：21 个引擎，被路由或任务引用时展开。
- **第五部分 质量门与交付**：G0–G10 质量门（四态判定）、存档卡三档、修改协议、分层自检、启动模板。

## 核心：角色心因驱动（引擎 13）

把角色写成观众的情绪开关，而不是让剧情拖着角色走：

- **四缺**：缺点（惹麻烦的性格）· 缺失（生命里少掉的东西）· 缺憾（过不去的旧债）· 缺陷（现实硬限制）——且必须有**社会集体性**，观众看到的不是角色，是自己。
- **三心因三事件**：先定目标角色与三次心因变化（撼动 → 逼迫 → 选择），再反推三个事件；事件像手指，按在角色缺口上。
- **替代成长**：外部成果必须沉淀为内在获得（王位 → 掌控感、洗冤 → 尊严恢复）；受众不是年龄段，是心理需求群体。
- 配套模板：【角色心因卡】【三事件三心因设计表】【篇章开发表】【心因自检】。

## 安装（电脑端）

前提：已装 Claude Code（`npm install -g @anthropic-ai/claude-code`）。

```bash
git clone <本仓库> && cd Mao
bash install.sh          # 复制 skills/fusion-story-director-studio 到 ~/.claude/skills/
```

装完重启 Claude Code。Skill 为自包含单文件，无需额外 reference 文件。

## 用法

系统按动作词和交付对象自动路由，不需要你记路径名：

| 你想要 | 可以这样说 |
|---|---|
| 审剧本，先别改 | 「审一下这个剧本」 |
| 改台词 | 「把台词改得像人话」 |
| 想点子 / 选题 | 「帮我想几个方向」 |
| 一句话创意扩成设定 | 「把这个概念扩成世界观和角色设定」 |
| 角色立不住、剧情不上头 | 「帮我把这段戏改成心因驱动」 |
| 打斗 / 动作分镜 | 「按顶级武指标准做这场动作分镜」 |
| 只要生成 Prompt | 「已有分镜，只要视频 Prompt」 |
| 参考图动起来 | 「这张图怎么动，给四种方案」 |
| 导演阐述 / 怎么演 | 「从导演角度说这场怎么导」 |
| 多集短剧 | 「拆成 X 集，每集 Y 秒」 |
| 完整执行包 | 「从剧本到成片的完整执行包」 |

**快捷指令**：`路径X` / `深度：精简·标准·全量·导演执行` / `只要 Prompt` / `继续` / `保存卡片` / `红队` / `锁定：……` / `禁止：……` / `假设继续`。

## 版本沿革

- **v7.0** `fusion-story-director-studio`：在 v6.1 故事开发内核之上，加入运行控制层（配置变量、输入成熟度、任务路由 A–Q）、质量门 G0–G10，以及导演执行侧的 8 个新引擎（分镜账本、叙事构图、AI Prompt、武术指导、独立审核、导演决策、世界观角色系统、剪辑声音）。
- **v6.1** `blockbuster-classic-story-studio`：五层架构故事开发系统，13 引擎，确立角色心因驱动内核。
- **v2.3 及以前** `jiang-writer`：美剧 Writers' Room 工作流 ＋ 竖屏微短剧模块（多文件 reference 结构）。

## 手机上的替代方案

Claude Code 是命令行工具，手机装不了。临时方案：在 Claude App 新建 Project，把 `SKILL.md` 贴进 Project Instructions。因本 Skill 是自包含单文件，手机端复刻很简单——一份 SKILL.md 即完整能力。
