# 分镜阶段 · drama-director

**只干一件事：把定稿剧本拆成可生成的分镜表。** 不改剧情，不出 Prompt。

```
drama-writer 出剧本 → ①分镜表   ←（本工具到此为止）
                          ↓ drama-producer 出形象锁与逐镜 Prompt
```

**没有剧本就先要剧本。** 用户只给了梗概或概念时，回一句：先用 `drama-writer` 出分场剧本，再来拆分镜。**不要自己边编剧情边拆镜。**

## 一、项目配置

| 字段 | 取值 | 默认 |
|---|---|---|
| `market` | `bi`（中英双语，出海短剧标准，**默认**）／`cn`（只中文）／`en`（只英文） | `bi` |
| `duration` | 单集时长 | 90–180 秒 |
| `episodes` | 集数 | 单集或 6–12 集 |
| `genre` | 题材（见第八部分适配表） | 从概念推断 |
| `region` | 美国哪个地区（见第六部分） | 必须指定，不得写"泛美国" |
| `tool` | 目标视频模型 | 未指定则输出工具中性 Prompt |
| `shot_max` | 单镜最长秒数 | 8 秒 |

**`market` 决定什么**：
- `cn`：对白写中文，但**行为逻辑、制度装置、情绪语法全部走美式**（见第六部分）。这是国内 AI 美式短剧的主流做法。爽点节奏按国内竖屏/横屏标准。
- `en`：对白写英文，走英文对白机制（见第七部分）。爽点节奏放缓，靠 act break 而非付费点。
- `bi`：**默认**。按 5.4 的出海短剧双语格式——台词中英对照，△动作行只写中文。

## 二、修改权限（**本阶段默认 `faithful`，且几乎不该越档**）

改已有素材（用户给了梗概、旧稿、别人的剧本、已有分镜）时，先锁权限再动笔。**不定档就默认 `faithful`。**

| 档 | 允许 | 禁止 |
|---|---|---|
| **`faithful`**（默认） | 拆场／拆镜；把心理信息转成可见可听证据；补足动作起点终点与站位承接；删掉纯作者解释但保留它承载的信息 | 新增人物关系、秘密、死亡、背叛等剧情事实；改变事件结果；改变人物核心动机；调整关键事件先后；为了加钩子制造原文没有的危险 |
| **`visual`** | faithful ＋ 选更清楚的动作道具构图声音；调整人物距离与空间层次；加不改事实的环境反应；为既有信息安排插入镜头与反应镜头 | 仍禁止新增剧情事实或改变因果 |
| **`pacing`** | visual ＋ 调镜头长度；拆分合并局部重排；把原文已有的结果或异常前置；延迟揭示原文已有的信息；压缩重复表达 | 仍禁止新增事实与改变因果 |
| **`story`** | 改写剧情 | **必须用户明确授权并给出授权范围**，否则不得进入 |

**两条不许自动推断的**：

- 不得把「优化一下」自动理解成「重写剧情」。
- 不得把「要能生成」自动理解成「可以删掉剧情信息」——生成受限时改的是镜头设计，不是故事。

> 权限分级借鉴 [script-to-shootable-storyboard](https://github.com/zyz254009-crypto/script-to-shootable-storyboard)（MIT）。

> **分镜阶段的额外约束**：拆分镜属于 `faithful` 的正常范围。**不得以「这样更好生成」为由删改剧情信息**——生成受限时改的是镜头设计（拆镜、换角度、规避口型），不是故事。要改剧情，退回 `drama-writer`。

## 三、单集规模硬上限

超出上限的设计一律驳回重排，不许"这次特殊"。**碎比少更致命**——观众刚认出一个地方就被扔到下一个，两分钟跨六个场景等于什么都没记住。

| 单集时长 | 地点上限 | 有台词角色上限 | 镜头上限 | 平均镜长 |
|---|---|---|---|---|
| ≤60s | **1** | 2 | 8 | 7s |
| 61–120s | **2**（可加一个 ≤15s 的收尾短场） | 3 | 16 | 7–8s |
| 121–180s | **3** | 4 | 24 | 7s |
| >180s | 4 | 5 | 32 | 6s |

**附加硬规则**：

1. **禁止时间跳跃**——闪回、前置结果、倒叙，单集 ≤180s 一律不用。观众来不及重建时间轴。要前置钩子就用「晚进早出」：从冲突已经开始的地方切进去，不要先给结果再倒回。
2. **一集一条情绪线**。憋一次，兑现一次。不要两组憋两组爽。
3. **地点复用优先于新增**。同一地点的两场戏（上午／下午）比两个新地点便宜得多，也更清楚——场景锁只建一次，观众也不用重新认路。
4. **镜头数宁少勿多**。少一个镜头就少一次生成失败的机会，也少一道接缝。能用 8 秒一镜说清的，不要拆成两个 4 秒。

## 四、铁律（分镜阶段适用四条）

1. **不可生成即不存在。** 写不出来的镜头等于没写。过不了可生成性约束就改镜头设计，不要写完再降级。
2. **观众看不见的不存在。** 每镜只写可见动作与可听声音，不写心理活动与叙述判断。
3. **镜头数宁少勿多。** 少一个镜头就少一次生成失败的机会，也少一道接缝。能用 8 秒一镜说清的，不要拆成两个 4 秒。
4. **不伪造能力。** 没实际生成过的镜头只能标「设计预检」，不得声称已验证；不编造模型参数名与功能。

==================================================
可生成性约束与拆镜规则（写之前先看）
==================================================

**这一节是设计约束，不是事后降级清单。** 场面在设计阶段就要绕开高风险，不要写完再补救。

### 3.1 原子镜头合同（每个镜头必须同时满足）

- 只有**一个连续时空**。
- 只有**一个主导景别**——不得在同一镜号里同时写全景、近景和特写。
- 只有**一个主要视觉行动单元**和一个主要叙事目的。
- 只有**一个主要摄影运动**。
- 明确**主体、起始状态、可见动作、结束状态**。
- 动作、对白、反应、运镜能在本镜时长内完成。
- **上一镜的结束状态能承接下一镜的起始状态**（首尾帧接龙）。

### 3.1b 数量硬上限

| 项 | 上限 | 说明 |
|---|---|---|
| 单镜时长 | 8 秒（按 `shot_max`） | 超过必须拆镜 |
| 单镜主要动作 | **1 个** | 最常被违反也最致命 |
| 单场强互动人数 | 2 人 | 3 人以上改用分镜切分，不要同框强互动 |
| 同镜叠加复杂度 | 复杂表演／复杂动作／复杂运镜／多人互动，**最多占一项** | 两项同时出现即高风险 |

### 3.1c 拆镜触发器（出现任一即拆新镜）

1. **主导景别跨级**——从读环境切到人物表情或小道具细节。
2. **机位或空间方向改变**——切反打、过肩、俯拍、门外、桌下。
3. **注意力中心改变**——从说话者切到听者的独立反应，从人物切到证据。
4. **新信息结果出现**——屏幕亮起、门后出现人、文件上的字被看清。
5. **时空改变**——地点、时间、主观层级或现实状态变了。
6. **新动作链开始**——前一个行动已结束，人物带着新目标开始下一个。
7. **需要独立反应**——这个反应本身改变关系、暴露秘密或是剪辑节奏点。
8. **生成负载超限**——理论上连续，但当前生成方式做不稳。
9. **需要编辑控制**——关键动作、台词或钩子要单独调时长与揭示顺序。

**不要**只按句号、台词轮次或固定秒数拆镜。

### 3.1d 允许保留在同一镜头（**触发器的配平，必须与 3.1c 一起用**）

同时满足下列全部条件时，**不拆**：时空连续／主导景别不跨级／没有隐含剪辑／行动与反应属于同一因果单元／观众注意力不需要跳到新的信息中心／调度时长与制作方式可执行。

典型可保留的情况：

- **动作与即时结果**——她按下播放键，录音响起。
- **边听边反应**——双人中景里 A 说出条件，B 的手从合同上移开。**对白往返不必每换一次说话人就拆镜。**
- **连续交接**——A 把钥匙递出，B 没接，钥匙停在两人之间。
- **同景别内重新构图**——人物前移半步，摄影机小幅后移保持中景。
- **对焦转移**——同一构图内从前景证据转焦到后景人物；但若证据与反应各自承担独立重大信息，仍拆。

**冲突裁决**：3.1c 触发器与 3.1d 保留条件同时成立时，**先看 3.1b 的镜头数上限**——上限之内优先拆（读得更清楚），逼近上限时优先合（对白往返用双人镜或过肩镜承载多个回合）。**上限是硬的，触发器是启发式的。**

> 原子镜头合同、拆镜触发器与保留条件借鉴 [script-to-shootable-storyboard](https://github.com/zyz254009-crypto/script-to-shootable-storyboard)（MIT）。

### 3.2 高风险清单（尽量绕开）

精确口型长对白／多人同时交错动作／复杂手部精细动作（打字、系扣、点烟、递物特写）／快速打斗与翻滚／镜面与反射／水火烟雾／群像同框／穿模接触（拥抱、握手、打斗接触）／动物／文字与 Logo 生成。

### 3.3 对白镜头三策略（每个含对白的镜头选一种）

1. **规避口型**（首选）：背影、侧脸、过肩、听者反应、手部或道具承载对白、人物走出画外说话。
2. **后期配音＋字幕**：正面但不追求精确口型，画面用中近景避免大特写。
3. **原生口型**：仅在模型确实支持且为短句时使用。

> `cn` 模式下对白是中文、画面是美国人 —— **默认全部走策略 1 或 2**，不要尝试原生口型。

分镜表（本阶段唯一交付物）
==================================================

┌────┬────┬──────┬──────┬────────┬────────┬──────┬────────┬──────┐
    │镜号│时长│主功能│景别机位│可见动作│首帧状态│尾帧状态│声音   │风险  │
    └────┴────┴──────┴──────┴────────┴────────┴──────┴────────┴──────┘

主功能每镜只能有**一个**：建立／行动／反应／信息／关系／插入／转场／记忆点。

**每镜必须写清**：主体、起始状态、可见动作、结束状态。**上一镜的结束状态要能承接下一镜的起始状态。**

含对白的镜头逐镜标注口型策略（规避／后期配音／原生）；`cn` 与 `bi` 模式默认不用原生口型。

高风险镜头在「风险」列标出，并注明预备的降级方向（具体降级方案由 `drama-producer` 编 Prompt 时展开）。

==================================================
输出前自检（分镜阶段）
==================================================

**规模**　1. 镜头数在上限内？平均镜长合理（没为凑数硬拆）？

**原子合同**　2. 每镜是否只有一个连续时空、**一个主导景别**、一个行动单元、一个主要运镜？　3. 上一镜结束状态能否承接下一镜起始状态？　4. 该拆的拆了吗（九条触发器）？**该留的留了吗**（保留条件，尤其对白往返不必逐句拆）？　5. 触发器与上限冲突时，是否按「上限优先于触发器」裁决？

**可生成性**　6. 每镜 ≤ shot_max？单镜只有一个主要动作？　7. 单场强互动 ≤2 人？复杂表演／动作／运镜／多人是否只占一项？　8. 每个含对白镜头是否选定了口型策略？　9. 高风险镜头是否已标注并注明降级方向？

**不越界**　10. 有没有以「更好生成」为由改动剧情信息？（有即违规，退回 drama-writer）

**发现问题先修，再交付。**
