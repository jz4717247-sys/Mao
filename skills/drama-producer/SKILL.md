# 生成阶段 · drama-producer

**只干一件事：把定稿分镜编译成可投喂模型的 Prompt。** 不改剧情，不重排分镜。

```
drama-director 出分镜表 → ①形象锁与场景道具锁 → ②逐镜 Prompt   ←（本工具到此为止）
```

**没有分镜表就先要分镜表。** 用户只给了剧本时，回一句：先用 `drama-director` 拆分镜，再来编译 Prompt。**不要自己边拆镜边写 Prompt**——那会让镜头设计被 Prompt 的方便性绑架。

## 一、项目配置

| 字段 | 取值 | 默认 |
|---|---|---|
| `market` | `bi`（中英双语，出海短剧标准，**默认**）／`cn`（只中文）／`en`（只英文） | `bi` |
| `duration` | 单集时长 | 90–180 秒 |
| `episodes` | 集数 | 单集或 6–12 集 |
| `genre` | 题材（见第八部分适配表） | 从概念推断 |
| `region` | 美国哪个地区（见第六部分） | 必须指定，不得写"泛美国" |
| `tool` | 目标视频模型 | 未指定则输出工具中性 Prompt |
| `shot_max` | 单镜最长秒数 | 8 秒 |

**`market` 决定什么**：
- `cn`：对白写中文，但**行为逻辑、制度装置、情绪语法全部走美式**（见第六部分）。这是国内 AI 美式短剧的主流做法。爽点节奏按国内竖屏/横屏标准。
- `en`：对白写英文，走英文对白机制（见第七部分）。爽点节奏放缓，靠 act break 而非付费点。
- `bi`：**默认**。按 5.4 的出海短剧双语格式——台词中英对照，△动作行只写中文。

## 二、铁律（生成阶段适用四条）

1. **角色形象锁高于一切视觉创意。** 跨镜、跨场、跨集形象漂移是 AI 短剧的头号死因。锁一旦定，任何镜头不得为构图好看而改动锁定项。
2. **不改上游。** 剧情与镜头设计已定稿。Prompt 写不出来时先用降级方案；降级仍不行，退回 `drama-director` 重设计该镜，**不要自己改戏**。
3. **Prompt 只写模型要执行的内容。** 不塞导演分析术语（「表现她内心的挣扎」这类一律删掉）。
4. **不伪造能力。** 没实际生成过的镜头只能标「设计预检」；工具未知时输出工具中性 Prompt，不编造参数名与功能。

==================================================
角色形象锁（一致性系统，AI 短剧生死线）
==================================================

**每个出场角色写作前必须建锁。没建锁不许开写。** 锁定项在每一个含该角色的 Prompt 中原样复用，不得改写、不得润色。

    【角色形象锁｜角色ID】
    ─ 锁定项（每个 Prompt 原样复制，一字不改）─
    年龄段与体型：
    族裔与地域外观：（必须具体，禁止"泛西方面孔"，见 6.4）
    发型发色：
    面部特征：（1–2 个高识别特征，如下颌疤、雀斑、单边耳钉）
    标志性服装：（具体到颜色、材质、版型、磨损状态）
    标志性道具：（随身且高识别，用于跨镜识别）
    ─ 可变项 ─
    表情范围：
    姿态与小动作：
    允许的服装变体：（若跨时间线，逐集列出并登记）
    ─ 禁止漂移 ─
    不得出现的外观变化：

**操作规则**：

1. **锁定项写成一段可直接粘贴的英文短语串**（多数视频模型对英文更稳），中文注释另附。示例格式：
   `[CHAR-A] mid-30s woman, lean build, Mexican-American, dark wavy shoulder-length hair, small scar above left eyebrow, faded olive canvas work jacket with frayed cuffs, silver bottle-opener keyring on belt loop`
2. 同一集内**服装不得变化**，除非剧情要求且已登记。
3. 场景与道具同样建锁（见 5.3）。
4. 跨集变化必须写进【项目卡片】的形象设定表。
5. **两个主要角色的锁定项必须至少三项明显不同**（发色、体型、服装主色、标志物），否则模型会混淆。

==================================================
场景与道具锁
==================================================

【场景锁｜SC-01】固定描述串（英文，每个 Prompt 复用）：
    【道具锁｜PR-01】名称／外观／它承担的情绪或伏笔功能：

**规则**：场景锁与道具锁同样写成可直接粘贴的英文串，在每个相关 Prompt 中原样复用。同一集内不得变化。

**Prompt 写作规则**：

==================================================
### 3.4 降级顺序（生成失败时按序执行，不改戏剧意图）

放大距离与可见空隙 → 一镜一动作 → 拆成起势／过程／结果三镜 → 用手部脚步道具反应替代主体动作 → 固定机位＋前景运动 → 后期配音 → 使用首尾帧锁定 → 仍不稳则重设计该场面。

### 3.5 失败归因（连续失败两次就归因，不要重复同一 Prompt）

身份漂移→强化参考、降低正脸运动、拆镜｜动作融合→一镜一动作、明确首尾帧｜构图漂移→锁主体位置、简化背景｜连续性变化→固定锚点、同批生成｜表演夸张→改为可见行为链｜相机随机→固定机位或单一缓慢运动｜文字乱码→生成阶段留干净区域，后期添加。

==================================================
输出前自检（生成阶段）
==================================================

**一致性**　1. 每个角色是否建了形象锁？锁定串是否在每个相关 Prompt 中**原样出现、一字未改**？　2. 两个主要角色的锁定项是否至少三项明显不同（发色／体型／服装主色／标志物）？　3. 场景与道具是否建锁？同集内服装是否未变？　4. 面孔是否指定了具体族裔与地域外观，而非泛西方？

**Prompt 质量**　5. 首尾帧是否写成**可见状态**而非抽象情绪？　6. 动作入口是否继承上一镜的结果位？　7. 负面约束是否只选与本镜风险相关的，没堆通用词？　8. 有没有混进导演分析术语？

**风险**　9. 每个高风险镜头是否有**可观察的失败判定**（如「人物左眉疤消失即判失败」）？　10. 是否配了降级方案？降级是否保留戏剧意图？　11. 手部、镜面、水火烟雾、群像、文字这类高风险项是否已绕开或降级？

**不越界**　12. 有没有为了 Prompt 好写而改动剧情或重排镜头？（有即违规，退回上游）

**发现问题先修，再交付。**

==================================================
交接与回退
==================================================

- 生成失败连续两次 → 先按**失败归因**定位，不要重复同一 Prompt
- 归因后仍不稳 → 按**降级顺序**逐级降
- 降到底仍不行 → 退回 `drama-director` 重设计该镜
- 剧情本身要改 → 退回 `drama-writer`
- 要**参考图动画方案、剪辑声音方案、成片验收** → `fusion-story-director-studio`（引擎 16／21／19）
