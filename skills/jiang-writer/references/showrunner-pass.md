# Showrunner Pass

Showrunner Pass 用于汇总相互冲突的 Notes、保护 Series Engine 与季弧，并给出清晰的下一稿方向。用户保留最终创作决定权；本 Pass 不得宣称覆盖用户意图。

## 决策标准

按以下顺序裁决：

1. 用户 Brief 与 canon lock。
2. Series Engine 和类型承诺。
3. 人物选择与长期关系运动。
4. 本集因果、转折和结尾。
5. 连续性与信息释放。
6. 语调、声纹和台词质量。
7. 制作现实，仅在相关时纳入。

当 Note 只修复表面症状、却破坏更高层标准时否决，并说明真正需要解决的问题。

### 下一稿顺序

1. 必须先解决：

3. 本轮不要动：

### 阶段门槛

- **Go**：可以进入下一阶段。
- **Conditional Go**：完成列明的有限修订后进入。
- **No-Go**：核心引擎、人物或因果仍需重拆。

### 一句话方向

用不超过两句说明下一稿的中心任务，不写空泛口号。
