# 角色声纹

声纹是角色在压力下组织语言、保护自我和处理关系的方式，不只是词汇或口头禅。

## 三层声纹

### 稳定指纹

选择 2–3 个最能区分角色的维度：

- 句长和语法复杂度
- 节奏、停顿、抢话或拖尾
- 直接、隐喻、术语、粗口或礼貌包装
- 主导回避方式
- 对权力的默认姿态
- 信息如何给、藏或控制

### 关系语态

同一角色面对老板、伴侣、孩子、竞争者和陌生人不应完全相同。记录他在每段关键关系中：

- 想扮演什么角色。
- 最怕对方看见什么。
- 更容易攻击、讨好、教育、表演还是沉默。

### 压力变体

分别测试角色在愤怒、羞耻、恐惧、亲密、被揭穿和获得权力时如何变化。变化必须仍能追溯到稳定指纹。

## 区分度检查

盖住角色名后检查：

1. 这句话的策略属于谁。
2. 用词与句法能否缩小到一至两名角色。
3. 相似声音是否来自共享阶层、职业或家庭，而非偷懒。
4. 若两人故意互相模仿，文本是否让这一行为可见。

不要求每句都能单独识别。真正标准是连续三至五轮对话中，角色的策略、节奏和自我保护方式是否稳定可辨。

## 使用量化数据

平均句长、停顿次数或特定词频可以作为诊断线索，不得成为机械配额。角色在危机中偏离基准可能正是有意义的变化；需要判断偏离是否被剧情支持。

## 防止声纹变成面具

- 不给每个角色硬塞口头禅。
- 不让“冷静角色”永远正确、短句、金句化。
- 不让“犹豫角色”每句都破折号和停顿。
- 不用职业术语代替欲望与关系。
- 不为了区分角色牺牲场景清晰度。
