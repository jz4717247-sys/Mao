# 竖屏微短剧（投流爽剧）

竖屏微短剧不是"缩短的美剧"，是另一套满足机制。用户明确要写抖音／快手／短剧 App 的竖屏连播剧时，本文覆盖 [structure.md](structure.md) 与 [dialogue-and-subtext.md](dialogue-and-subtext.md) 中与本形态冲突的默认值。不写这类项目时不要加载本文。

## 形态定义

- 竖屏 9:16，单集约 60–120 秒，一部 40–100 集连播。
- 变现靠投流：前几集免费引流，后段付费解锁。留存曲线直接决定生死。
- 观众在信息流里滑动，随时可划走。每一秒都在和"划走"竞争。
- 常见类型：重生复仇、逆袭打脸、赘婿战神、豪门甜宠、马甲身份、先婚后爱。

## 与美剧默认值的关键反转

美剧里的"风险信号"，在本形态里多数是**类型承诺**，观众为它们付费。不要用美剧的克制感磨掉它们。但反转的是"允许"，不是"免检"——爽点仍要被挣来，仍要属于这个角色。

| 手法 | 美剧判断 | 竖屏微短剧判断 |
|---|---|---|
| 内心 OS／画外音 | 作者替角色解释，风险 | **刚需**。承担重生记忆、身份反差、情绪直给，是低成本高效的信息通道 |
| 情绪命名／主题直给 | 风险信号 | 爽点句可以直说。"这一世我要你连本带利还回来"就是买点 |
| 打脸金句 | 万能句、作者腔 | **类型核心**。但必须是这个角色的狠，且落在具体的人和事上 |
| setup 全回收 | 工整过度 | **资产**。留存靠钩子兑现，不故意留哑火子弹 |
| 扁平／标签化角色 | 冲突同质化 | 配角可功能化（恶毒女配、势利眼、打脸对象）。但主角要有一个"钩人反差" |
| 巧合／金手指 | 削弱因果 | 重生、系统、马甲是本类型的引擎前提，不是偷懒——但兑现要有代价和节奏 |

**仍然守住的**：爽点要有"憋"才有"爆"；打脸要落在具体行为而非空喊；主角的狠要有来处（前世／屈辱）；金句是角色的，不是可无损换到任何剧的作者万能句。区分"这个角色的陈词滥调"和"作者的偷懒"，标准和 [ai-patterns.md](ai-patterns.md) 一致，只是阈值放宽。

## 钩子系统

留存是本形态第一指标，钩子是留存的唯一杠杆。

- **开篇钩（前 3–8 秒）**：第一集开场即冲突或即羞辱，不做世界观铺垫。观众先看到"惨"或"爽"，再补背景。
- **集内钩（每 15–25 秒）**：一个小反转、小爽点或新信息，防止中段划走。
- **集尾钩（每集必须）**：必须是**具体悬念或爽点预告**，不是主题陈述。
  - 废钩（改）："这一世我只要真正的伙伴。"——价值观陈述，观众不为它停留。
  - 真钩（用）：镜头压到反派脸上，他手里攥着一张主角以为已经烧掉的契约。——观众为"那是什么／接下来怎样"停留。
- **付费点钩**：付费解锁那一集的集尾，钩力要最强（最大反转或最大爽点前一刻断），这是转化的命门。

## 爽点与打脸节拍

- **憋—爆**：让打脸对象先得意到顶点（嘲笑、羞辱、下战书），把观众的憋屈拉满，再一击落下。零铺垫的爽会迅速疲劳。
- **爽点回旋镖**：最好的打脸是对方的恶意反噬自己（她逼你喝的酒，最后泼在她自己脸上）。
- **代价可见**：逆袭不能永远零消耗。偶尔让主角赢得付出，爽感反而更实。
- **节奏**：投流剧的爽点密度远高于长剧。宁可一集一个清晰爽点，不要三个模糊的。

## 名词与信息控制

竖屏观众记不住设定。

- 世界观专有名词开篇只留一个核心，其余靠画面和处境显露。
- 数值、等级、组织名能省则省；"至高精华""八级""学院屏障"堆在一起观众只记得"很厉害"。
- 让观众先听懂"谁会失去什么／谁要打谁的脸"，再听规则。

## 单集微结构

一集 ≈ 钩子 → 冲突／升级 → 爽点或反转 → 集尾钩。

- 没有走廊反思、没有为观众复述上集的"同声传译"场。信息靠画面前推，悬念靠集尾钩后拉。
- 甜宠／CP 线：男主或甜宠对象要**早露脸**，剧名承诺甜宠就不要让对象拖到十集后才出现。
- 结尾承接：本集集尾钩直接是下一集的开场问题，连播不留缝。

## 投流剧常见死法（写作即诊断）

1. 开篇铺垫世界观，前 8 秒没有钩子。
2. 集尾用主题金句收，而不是具体悬念。
3. 爽点太顺、零代价，第三集起观众腻。
4. 专有名词堆砌，观众记不住谁是谁。
5. 甜宠对象／男主出场太晚，CP 线起不来。
6. 主角一味正确高效，没有"钩人反差"或可代入的屈辱。
7. 付费点选在平淡处，转化崩掉。

## 制作适配

竖屏微短剧多用 AI 视频生成或轻量实拍。可拍性检查读 [director-pass.md](director-pass.md)，本形态额外锁定：

- 单场同框 ≤2 人；三人以上戏用单人镜＋过肩反打分离，不做真实群戏。
- 单镜头 ≤8 秒；避开复杂运镜、大幅位移、精细手部、镜面反射、群演指向性表演。
- 优先固定机位、面部特写、物件特写、空镜；情绪靠反应镜承载，替代成本高的台词。
- 需要中英对照拍摄稿时，中文为拍摄原句，英文为对照译句，同一潜台词，不各写各的。
