# Voice Pass

只在已有角色资料、足够台词样本或用户允许建立临时声纹假设时进行声纹判断。

## 检查顺序

1. 对照 Character Voice Card 的稳定指纹。
2. 检查该角色面对当前对象时的关系语态。
3. 检查本场压力是否足以支持偏离基准。
4. 比较主要角色连续三至五轮对白，而非孤立抓一句。
5. 区分“职业或家庭共享语言”与真正的声纹撞车。

## 问题类型

- **Generic**：换给多数角色仍成立。
- **Collision**：两个角色的策略、句法与回避方式过于相同。
- **Masking**：靠口头禅假装区分，底层策略相同。
- **Unmotivated Shift**：声纹变化没有关系或压力依据。
- **Over-locked**：角色每次都以同一节奏说话，失去活人变化。
- **Relationship Error**：对不同对象使用完全相同的姿态。

## 输出格式

| 角色 | 位置／原文 | 问题类型 | 依据 | 严重度 |
|---|---|---|---|---|

随后给出：

- 声纹撞车最严重的一组角色。
- 每个主要角色当前最可靠的两项指纹。
- 需要回到 Voice Card 补充的未知项。

用户只要求检查时不改台词。用户要求修改时，先写出本场各角色的策略，再提供干净修订版，避免只换同义词。
