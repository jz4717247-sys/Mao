# 通用 AI 写作模式：上下文扫描

本表用于识别风险，不是字面黑名单。先判断句子在角色、关系和场景中的功能，再决定保留、压缩或重写。

## 高风险模式

### 作者替人物总结

- 角色准确概括自己的人格模式、关系问题或本集主题。
- 一句台词同时交代背景、动机、情绪和结论。
- 冲突结束后双方立刻使用同一套心理学语言互相理解。

### 万能情感句

例如“我只是想让你知道”“我们不能再这样下去”“这一切比我们更重要”。问题不在词本身，而在它们是否可以无损换到任何角色、任何项目。

### 工整过度

- 每个 setup 都在同一集整齐回收。
- 每名角色都完成对称弧光。
- 每场都以反话、打断或物件隐喻收尾。
- 场景轮流完成“铺垫—解释—金句—反应”。

### 冲突同质化

- 所有人都擅长完整表达边界和需求。
- 所有人都用短句、反问和停顿表现高级感。
- 反派只负责阻碍，没有自己的现实优先级。
- 主角总做最正确、最高效且道德完整的选择。

### 抽象替代具体

- 使用“信任、选择、真相、保护、命运、放下”等抽象词，却没有对应的具体行为或代价。
- 动作行只写情绪形容词，没有可表演的行为。
- 场景以“气氛变得紧张”代替谁做了什么。

## 扫描方法

对可疑句依次问：

1. 换成另一个角色是否仍成立？
2. 删除后，观众是否已经能从行为得到相同信息？
3. 这句话是否改变对方的策略或后续选择？
4. 角色说它需要付出什么风险？
5. 这是角色有意使用的陈词滥调，还是作者缺少具体性？

只有病因明确时才重写。不要要求每稿必然存在固定数量的“假句子”。规则库只在用户明确要求更新 Skill 时维护，避免无限追加样本。
