# 竖屏微短剧：内容合规

投流微短剧要过平台审核才能上线，非合规稿等于废稿。本文用于合规审查，加载时机：竖屏投流剧定稿前，或用户要求做合规检查。审查报告与剧本正文分开交付，不把清单混进成片正文。

合规随平台政策与地区变化，本文是常见基线，不替代平台最新审核细则。判断存疑时，标为待核而非放行。

## 七个合规维度

1. **政治敏感**——国家形象、历史事实、领土主权、民族关系。
2. **暴力**——血腥细节、虐待展示、犯罪教唆、暴力美化。
3. **色情**——裸露、性行为、性暗示、未成年相关、性骚扰美化。
4. **违法行为**——涉毒、赌博、诈骗、非法集资、隐私侵犯。
5. **价值观**——私刑正义、拜金、职场 PUA、家暴等灰区导向。
6. **关系不当**——强吻、过大年龄差、师生恋、复仇过度。
7. **表现手法**——恐怖氛围、迷信、奢侈消费炫耀、医疗常识错误。

## 红线与灰区分级

**P0 红线（零容忍，出现即毙）**：
- 损害国家形象、篡改重大历史与主权事实。
- 特写伤口、血液喷射、肢体分离等血腥细节。
- 任何程度的裸露或性行为画面。
- 涉未成年的性相关内容。
- 具体到可模仿的犯罪/涉毒/诈骗操作步骤。

**P1–P2 灰区（敏感但可技巧规避）**：
- 私刑/法外开恩——让公权力或正规程序最终介入，主角不越法定红线。
- 霸道强吻、过大年龄差、复仇过度——补足对方回应、成年设定、代价与善恶有报。
- 赌博/暴力情节——点到为止，不展示可操作细节，不美化。
- 拜金/炫富——让价值观有反拨，不把奢侈当唯一成功标准。

## 审查执行

**逐集自检**：红线内容、台词合规、暴力程度、价值观导向、是否遵守"善恶有报"、版权（人名/品牌/音乐/桥段）。

**全剧自检**：核心设定是否触线、主角手段的道德底线是否守住、反派下场是否交代、整体导向是否正向。

**题材高发踩坑**：
- 战神归来——暴力尺度、私刑复仇。
- 霸道总裁——强吻、职场 PUA、年龄差。
- 甜宠——擦边亲密尺度、未成年感设定。
- 伦理/复仇——过度以恶制恶、私刑正义。

## 出海补充

海外发行时，红线随目标地区法规与文化重设：分级制度、宗教与种族敏感、LGBTQ 相关尺度、暴力与性的当地标准都可能与国内不同。不要把国内合规版直接等同于海外可发版，按目标市场单独过一遍。
