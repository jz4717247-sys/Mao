# Voice Card 示例｜《离婚后，我成了女王》

本示例展示填写粒度，不提供可跨项目复制的万能台词。

## 薇拉

### Character Core

- 身份：31 岁，家族企业继承人。
- 表面目标：查清旧案并夺回公司控制权。
- 深层欲望：停止用忍耐证明自己值得被爱。
- 核心矛盾：她越擅长控制局面，越接近自己痛恨的掌控者。

### Stable Fingerprint

- 把情绪压缩成可核对的事实；冲突越大，句子越短。
- 很少抢话，善用停顿迫使对方补充。
- 面对权力不抬高音量，而是缩小对方可选择的范围。

### Relationship Registers

| 对象 | 想扮演的角色 | 语言／策略变化 |
|---|---|---|
| 朱利安 | 已经不再需要解释的人 | 只回应事实，不接他的悔意表演 |
| 康斯坦丝 | 不会被重新定义的对手 | 要求证据和具体动作，拒绝讨论“家族应该怎样” |
| 迪恩 | 能够平等合作的人 | 允许较长句，但一察觉依赖就迅速划界 |

### Pressure Variants

- 被揭穿时：不先辩解，承认最小事实，再夺回问题定义权。
- 亲密时：句子变长，但会借具体安排代替请求。
- 失去权力时：开始重复对方的词，暴露平时隐藏的失序。

### Collision Guard

- 最易与康斯坦丝撞在“冷静、短句、控制节奏”。
- 必须守住：薇拉依赖可核对事实；康斯坦丝依赖身份、规矩和情感债。

## 朱利安

### Character Core

- 身份：33 岁，前 CEO，长期扮演“好儿子”。
- 表面目标：挽回薇拉并保住体面。
- 深层欲望：有人替他证明他并非主动伤害别人。
- 核心矛盾：他用沉默避免做坏人，沉默本身却是选择。

### Stable Fingerprint

- 句子常停在责任出现之前；习惯延迟和补充说明。
- 用“我知道”暂时占据道德位置，但随后暴露他并没有行动。
- 面对强势者时把愤怒转成自我贬低或技术细节。

### Relationship Registers

| 对象 | 想扮演的角色 | 语言／策略变化 |
|---|---|---|
| 薇拉 | 值得被再给一次机会的人 | 先承认小错，绕开最关键的主动选择 |
| 康斯坦丝 | 能够独立的儿子 | 先用公司语言，受压后退回沉默 |
| 迪恩 | 仍拥有合法位置的前任 | 句子更完整、更具攻击性，偶尔模仿薇拉的冷静 |

### Pressure Variants

- 愤怒时：不是变流利，而是突然说出一件过度具体的小事。
- 被揭穿时：先争论措辞，再承认事实。
- 真正承担责任时：删掉理由，但这一变化必须由行动提前证明。

## 康斯坦丝

### Stable Fingerprint

- 把个人欲望翻译成家族、规则和责任。
- 通过重新命名事件改变谈话边界。
- 恐惧越强，礼貌越完整，给出的选择越少。

### Collision Guard

- 与薇拉都不依赖大声，但控制来源不同。
- 康斯坦丝的台词必须让人感觉她在建立制度，而不仅是在说狠话。

## 迪恩

### Stable Fingerprint

- 先交付工具、数据或行动，再轻触情绪。
- 很少请求原谅，也很少替别人决定；压力下会把关心包装成流程。
- 获得权力时反而减少语言，避免变成“完美理解型工具人”。

### Collision Guard

- 与朱利安都可能少谈自己。
- 必须守住：朱利安用沉默逃避选择；迪恩用沉默给出选择空间，但这种克制也可能隐藏控制欲。
