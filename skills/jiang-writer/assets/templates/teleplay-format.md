# TELEPLAY FORMAT｜基础模板

按项目约定使用幕标题。流媒体无显式幕标题时，保留内部段落结构但不必写在页面上。

```text
TEASER

INT. LOCATION - DAY

Action lines describe only what can be seen or heard. Keep paragraphs readable
and let performance turns have space on the page.

                    CHARACTER
          Dialogue.

                    OTHER CHARACTER
          Dialogue.

The action changes the situation.

END OF TEASER
```

## 使用原则

- Scene Heading 使用 INT./EXT.＋地点＋时间。
- 动作行用现在时，避免摄影说明，除非镜头本身承载必要信息。
- 第一次出现主要角色时按项目规范突出姓名，并给可拍、可见的简短介绍。
- Parenthetical 只在读法或动作无法从上下文判断时使用。
- 不在剧本正文解释角色无法被看见或听见的心理结论。
- 电话、短信、屏幕文字、画外音和蒙太奇采用项目统一格式。
- 场号、页码、修订色页和 Continued 标记服从制片方模板；没有要求时不要伪造生产稿编号。
- 中文稿可使用同样结构，不必硬套英文居中空格；重点是层级一致、动作可演、对白归属清楚。
