# 创意交付检查

先修影响故事成立的问题，再修措辞。用于本轮创意方案与大纲，不要求正文、读演、成片或市场测试已完成。

## 必须修复

- 用户锁卡、禁项、已选人物或承诺丢失；限定方向却擅自重抽。
- 输出成分场、连续对白、逐集剧本、分镜或媒体提示词；把完整创意包误叫“完整剧本”。
- 概念无法用一个具体事件理解；用新名词替代人物目标与因果。
- 主角没有主动策略，对手没有独立利益；特色只有外观标签。
- 关键转折/终局靠凭空能力、证据或知情解决，已建立规则被偷偷改掉。
- 没有大纲结局，或只列“前期受辱—中期升级—后期翻盘”等空阶段。
- 将原创新增称来源事实；将资料数量、历史快照或标题使用称当前爆率。
- 把待核、断句或原声依赖未核的网络表达列为可用已核梗。

## 本轮范围是否齐全

只要方向：候选数量符合请求，差异来自任务、策略、关系和后果，有明确推荐、短板与依据边界。

完整落地：选题定位、发动机、核心角色、辨识特色与声口、原创口头禅、热梗使用规划、因果大纲和结局全部可读。零梗和无口头禅可以有理由；不能漏掉规划层。用户指定完整群像/逐集事件大纲时逐项交齐，未要求则不默认16人60集。

局部修改：保留其余已认可内容，只调整必要联动；不擅自换全世界观。

## 创意与易懂性

1. 一句话能说清谁现在必须做什么、为什么、谁拦他、怎样解题和付什么代价吗？
2. 每张锁卡在行为或关系中发挥作用吗？移除它是否改变关键事件？
3. 匿名化候选的名词后，任务来源、解法、对手调整和兑现是否仍不同？多数仍是同一种议价/开店/闯关则重构，不能因标签不同宣称脑洞通过。
4. 开局、三个不同发展、阶段回报和终局怎样连成因果？是否只靠扩大敌人和光效？
5. 搞笑有具体预期与结果错位吗？猎奇异常可在一次事件中验证吗？普通读者是否需要读设定词典才能懂？

“激进”操作标签或两个日本JP码不是原创认证。改变目标、权力关系、时间/信息组织或成功的代价，比增加设定词数量更有意义。不声称没检索就证明世界首创。

## 人物与语言规划

主角换成任何人是否仍成立？外形/声音记忆点是否具体，经历与解法是否独特？对手在新局势会怎样反制？配角是否只有震惊与崇拜？关系双方的需求与误信是否具体？

按 [人物设计](humanization.md) 比较角色声口；口头禅有使用条件、私人目的、禁用和后期变体。不是每个人都靠一条金句或地方口音鲜活。热梗来自适用语境，有角色来源、节点、普通替代与零梗区；不把悲痛、救援指令和关键承诺变成笑词。

## 世界、结构和三路线

核心规则有触发、上限、代价和有效反制；人物知情有来源。多视点/循环分开事件事实、叙述顺序和人物所信，不用后段新事实悄悄推翻前段。每次胜利改变资源、关系、目标或风险，伏笔有回收，大纲结局回答开局。

| 路线 | 创意验收重点 |
|---|---|
| 抖音超创 | 生活入口与异常易懂，错误策略有反馈，系列变化不归零；不要求温情升华 |
| AI仿真人 | 资源与关系具体，角色有能动性，特色可表演，承诺/原谅有行为后果 |
| AI动漫 | 规则与形态有功能，视觉奇观改变局势，升级改变任务和关系；不要求全是战斗 |

奇观写变化前、变化与后果即可，创意阶段不要求镜头、资产和API参数。制作适配判断有具体负担，未实测不承诺成本或成片时长。

## 依据与结束点

对应机制回到具体解析因果及限制；独立故事族不与文档数混用，完整组合不与组件支持混用，日本参考与本地核心分开。当前市场/热梗要求实际查新；无法获得留缺口，继续给创作判断。

必要记录 `问题 → 影响 → 修订后的创意项 → 复核结果`；修复示例也只到提案与大纲。交付停止于本轮需求。通过意味着纸面检查通过，用户审阅、笑感、创新效果与市场表现分别等待真实反馈，不称已验收。
