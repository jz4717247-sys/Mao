# 概念、人设、世界与结构的完整构建

用于原创方向深化、人物与世界设计、完整系列事件大纲；输出到创意层，不生成剧本正文。快速建议只取能改变决策的部分；不要把工作表铺成用户没有要求的报告。日本作品是补充类比，用户解析剧资料仍是主要机制依据。

## 1. 把概念变成有后果的异常

概念写出六件事：观众原来相信的常识、被改变的一条关系、触发事件、谁首先受益、谁承担损失、为什么无法恢复原状。大尺度与陌生名词不能单独增加想象力。

| 检查 | 能构成故事的答案 | 需要重构的情况 |
|---|---|---|
| 概念必要性 | 异常改变人物的解题策略、关系或选择代价 | 去掉设定，事件仍完全相同 |
| 主角必要性 | 身份、欲望或误信使这个人比别人更难/更会处理异常 | 换任意人只需换名字 |
| 双向后果 | 优势同时损坏另一项人物在乎的东西 | 增大能力但不改变任何关系 |
| 入口可见 | 观众看见一次目标、尝试和反馈，即可理解初始规则 | 先听一页世界历史才能懂事件 |
| 可持续变化 | 同一异常允许不同策略、任务和利益冲突 | 连续三集只是重复一次梗 |
| 停止条件 | 知道什么状态意味着本阶段完成，终局选择可回收概念 | 只能不断追加更大敌人 |

用户要求更大胆时，可重构身份类别、关系定义、时空组织、资源流转或叙述视角。选择一个主要异常，再选一个会让解法变难的矛盾；不把若干参考作品的能力、组织、造型和剧情整套拼接。用 [日本想象力操作库](japan-imagination.md) 找类比，原创因果由作者完成。

## 2. 人设是行为系统，群像是利益网络

每位主要人物需要：可判成败的外部目标、内在需要或误信、当前控制/缺少的资源、惯用策略、策略造成的副作用、底线、关系盲区、说话与身体习惯、在关键局势中的两难选择。喜剧人物可以坚持错误或不成长，但错误需要产生可继承的后果。

给主角和关键对手各写三次选择，而非只给主角设定一堆特征。搭档不必互补到没有冲突；共同目标与无法兼得的利益要同时成立。

关系表只保留实际有戏的人：

`甲 → 乙：想拿到什么 / 能提供什么 / 误以为对方什么 / 隐瞒什么 / 哪次选择改变关系`

避免把女性、反派、怪物、家人仅作为奇观的反应镜头。检验配角：暂时移除主角，他还会争取什么？对手按自己的资源与知情状态调整策略，不能为了主角新招突然降智。

## 3. 世界观要能产生行动

世界至少分物理/超自然规则、身份与社会制度、资源经济、日常生活、公共认知五层。写实路线不需要超自然规则；法律、合同、家庭责任、信息渠道和声誉同样会限制行动。与当前冲突无关的层可以暂不展开。

每条核心规则写成一张可执行卡：

| 字段 | 必须说明的事 |
|---|---|
| 触发 | 谁在什么条件下做什么 |
| 效果 | 哪个状态发生何种可见变化 |
| 权限 | 谁能使用、谁被排除、能否转让 |
| 上限 | 哪些事明确做不到，距离/次数/时间/信息是否有限 |
| 代价 | 使用者及旁人分别失去什么，代价何时结算 |
| 知情 | 观众、主角、对手此时分别知道/误信什么 |
| 验证 | 首次示范、失败试验、误用后果和有效反制 |
| 连续性 | 效果会否持续、能否撤销、终局怎样结束 |

原创规则可以自由创设，但高潮的解法须来自之前可见的规则或人物选择。先用反例试验：反复使用、让别人使用、拒绝使用、退出任务、公开秘密、让最有资源的人接管时，会发生什么？若某个办法能立即无代价解决全剧，补限制或改变目标；不临时发明一个禁令堵漏洞。

制度层要有执行者与获益者；资源层记录来源、消耗、分配和短缺；生活层说明异常如何影响吃饭、居住、工作、亲密与照护。制度可以荒诞，但人物应认真应对可见后果。

## 4. 结构有三个尺度与三份时间表

三个尺度分别回答：全剧要完成什么；每阶段怎样换策略或改变关系；一个事件单元怎样完成具体尝试。只有用户指定集数时才分配逐集事件，不默认固定集数。长篇信息不能全塞进首集，短片也不必留整季悬念。

| 结构模型 | 适用发动方式 | 阶段真正变化的东西 | 常见失败 |
|---|---|---|---|
| 单元任务与状态积累 | 职业、经营、社区、委托 | 客户问题、策略、伙伴债务、资源存量 | 每集换人但关系和资源归零 |
| 关系反复与选择转向 | 家庭、爱情、搭档 | 谁依赖谁、谁让步、谁承担代价 | 反复误会不产生新行为 |
| 重复处境与差异实验 | 时间循环、重生、训练 | 新知、职业能力、记忆与目标 | 把同场拍三次却没有新因果 |
| 多视点与信息重估 | 悬疑、群像、隐藏身份 | 可见证据、认知和道德判断 | 后段靠未铺垫事实推翻前段 |
| 规则任务与目标升级 | 冒险、竞赛、异界、能力 | 能力边界、地图、敌人策略、目标意义 | 只增加数值和怪物体积 |
| 后果链与世界显露 | 猎奇、制度寓言、黑色喜剧 | 异常影响范围、参与者、责任归属 | 新设定凭空追加，与旧行动无关 |

模型来自跨作归纳，属于可选方法；不要求每部故事完成固定英雄旅程或固定三幕时长。

三份时间表分开：`事件实际发生顺序`、`作品向观众提供的顺序`、`各角色此时相信的版本`。多视点、倒叙、循环尤其需要。改叙述顺序可以改变观众理解，不能偷偷改变已经发生的事实。源资料仅覆盖简介或前几集时，分析也只到该范围。

阶段卡用 `入场状态 → 主动尝试 → 对手/规则反馈 → 得失 → 新策略 → 阶段兑现 → 未清后果`。初期三次发展至少在行动策略或关系选择上不同；终局写“最终选择如何回应开局承诺”，不默认更大危机。

## 5. 让想象力进入完整创意包

用一句因果句、关系网络、少量核心规则和阶段卡锁定当前故事，再按 [交付合同](output-contract.md) 完成角色特色、口头禅、热梗使用规划与全剧大纲。大纲须有触发、尝试、反制、状态变化、转折与结局。资料出处和类比放简短附注；不写场标、连续对白或逐拍动作。

自审时先问五件事：异常是否改变行动；欲望是否互相冲突；规则能否回读；每次胜利是否改变状态；结尾是否兑现开局。用户要搞笑时，再检查笑点来自误解、策略碰撞、身体/空间动作还是言语；不能只给人物加几个广告式口号。不要因参考作品严肃就强制移除喜剧，也不要把所有严肃人物变成说梗机器。
