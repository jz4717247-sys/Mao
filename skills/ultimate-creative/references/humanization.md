# 核心角色、辨识特色与口头禅

将去AI味方法前移到人物创意阶段：先确立欲望、处境、关系和说话策略，再设计辨识点。借鉴 `screenplay-humanizer-cn` 的信息边界、人物声口、潜台词与可见载体；这是开发方法，不是461份解析新增的统计结论，不判断谁写了文字。必要方法已包含，不依赖外部 Skill。

## 先让这个人不可替代

一个主要人物至少回答：今天想拿到什么？为什么非拿不可？常用什么办法？这个办法为什么会惹祸？控制和缺少什么？不肯承认什么？愿意为谁付什么代价？

主角有独特解题策略、私人矛盾和选择压力；不是唯一拥有万能系统的人。对手有自己的目标与风险排序，会根据主角的行动调整。搭档既有共同任务也有无法兼得的利益。配角移除主角后仍有想做的事。

关系用 `甲想从乙得到什么 / 乙能拒绝靠什么 / 双方误信 / 哪次选择改变关系` 表达。不是“欢喜冤家、亦敌亦友”四字结束。只给实际推动故事的人写详卡；群像人数以用户要求和故事需要为准。

## 辨识特色有三层

| 层次 | 设计方法 | 对大纲的作用 |
|---|---|---|
| 一眼/一耳可认 | 少量稳定的外形轮廓、穿着、脸部记忆点、声音或口音；写清具体程度 | 被误认、被低估、隐藏身份困难、别人怎样接近他 |
| 接触后有反差 | 自称与实际行动的矛盾；对强者/熟人/弱者策略不同 | 产生误解、喜剧反馈、亲密或权力冲突 |
| 关键时刻不可替换 | 特定经历、手艺、局限、底线和有代价的选择 | 决定开局失败、阶段解法或结局；换人则因果不同 |

给主角至少一个具体视听记忆点，同时给一个影响行动的特质；不要每人堆五种奇怪装饰。纹身、黄毛、牙缝、地方口音可以使用，但不能自动等同善恶、聪明或身份高低。特点要有缘由，口音以可懂为先，不靠错别字把对白变成方言猜谜。

身体习惯是压力下的策略载体，例如没把握时先擦工具、要拒绝时把椅子转回去、想留下却先整理离开的东西。指出其作用和何时改变即可，不展开成逐拍动作戏。

## 声口卡

| 字段 | 需要具体到什么程度 |
|---|---|
| 当前身份与利益 | 他怕哪个人拒绝，能用什么筹码 |
| 惯用说话策略 | 命令、试探、回避、逗弄、安抚、讨价等；不是只写“嘴毒” |
| 句式倾向 | 长短与解释习惯，不规定统一字数；是否先提条件或先安慰 |
| 称呼与回应 | 面对不同人怎样称呼、问问题、打断或沉默 |
| 口音与表达来源 | 生活经历、职业或社交渠道；没有口音也可以鲜明 |
| 压力变体 | 嘴硬者真怕时是否变短，爱解释者承诺时是否直接 |
| 不说什么 | 哪个私人需要被掩盖；并非每个人都必须有秘密 |

遮掉名字比较声口卡：角色靠目标、策略、对象和句式仍应不同；不能只替换语气词。常用礼貌话、救援指令允许重合。角色可以长句、沉默或正式宣言，不默认全员贫嘴、粗口、金句。

MBTI仅在用户需要时作为行为假设，先有经历与利益再看类型。同类型可以相反，不把ENTP规定为贫嘴、ISTJ规定为机器人。用户要求16型时全部列齐，并让各人的目标、筹码、关系与关键选择有区别；不能每型配一个网络词就完成群像。

## 口头禅设计

优先从误信、职业经验、规避责任的习惯或私人承诺中原创。口头禅可以暴露策略，也可以成为关系中的小暗号。每个核心角色通常0–1条主句，按需求增加压力变体，不要求人人口号化。

| 必需信息 | 示例（原创规划） |
|---|---|
| 短句 | “先别夸，坏的还没算。” |
| 来源与隐藏目的 | 老维修工习惯先报故障，怕别人期待过高也怕被当神医 |
| 触发 | 小修成功、别人提前吹捧时，用来控制期待 |
| 不用 | 伤亡确认、真正承担责任时直接说明能做和做不到的事 |
| 后期变化 | 从给自己免责转为替徒弟扛责，少说“没算”，开始明列可承担的部分 |

这是短句与用途卡，不是角色交替对白。主句不是每个节点都重复：初次认识、中段被人误读、后段含义改变，回收要有关系或行动收益。若删掉口头禅就认不出人物，补目标与策略。

## 热梗不是人格身份证

口头禅是角色长期的原创表达；热梗是有来源、时期与具体社交用途的偶发借用。按 [获取与筛选](meme-workflow.md) 规划，先说明普通表达的目的，再判断梗是否增加反馈。嘴硬、遮羞、讨好、自嘲、给体面可能适用；冷静指令者和正式对手可长期零梗。

不要给每个角色固定发“我超威/包的/已老实”来区分人格。不能用网络安慰自动解决真实伤害或改写关系。英文与历史人物不直接套现代中文梗；没有合适已核材料时保留原创口头禅和普通表达。

## 三条路线的特色落点

| 路线 | 先落地什么 | 允许保留 |
|---|---|---|
| 超创 | 奇怪规则迫使人物使用自己的办法；错误策略引出具体笑点反馈 | 猎奇、夸张、视觉错位，不强迫升华 |
| 仿真人 | 请求/拒绝、生活物件、关系差异；外形与声音可表演 | 礼貌、长句、沉默、适度口音，不把全员变网红 |
| 动漫 | 能力与性格互相妨碍，形态和任务有因果；打斗中的选择具有角色性 | 宣言、夸张反应、系统角色，不抹掉类型风格 |

## 人物开发复核

先锁用户认可的事实，再检查因果与知情来源、欲望和关系、辨识特色与声口，最后查口头禅与热梗。不能为了鲜活新增万能能力、未经铺垫秘密或角色知道的信息。

交人物方案与必要修改理由，不交场景重写。未读原稿不能造前后对照，未读演不能宣称演员认可；纸面清晰度不等于观众效果。词句像模板只能作为复核线索，不输出AI作者概率。
