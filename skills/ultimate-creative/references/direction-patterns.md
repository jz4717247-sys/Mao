# 跨故事方向模式：从证据到新组合

本页提供选题的因果类比，输出到方向与大纲；开局和发展只用事件概述，不扩为分场与对白。

以下13组由全库研读中选出的跨案例因果类比构成。每组列3–4个独立故事族，逐个给实际来源；这是**模式的具名最低支持量**，不是该完整标签组合在全库的发生率，更不是爆款概率。每组内的相似性是创作归纳，仍须检查差异和未兑现部分。

方向卡使用顺序：先锁用户卡 → 选1个主模式、最多1个辅模式 → 补具体目标与代价 → 用 evidence_engine 查询实际标签组合 → 比较开局事件概述、三次发展兑现和制作适配。模式可以共用组件；不得将各组支持数相加声称独立总量。

## DP01 反差身份＋非血缘照料＋有限资源共享

**因果链：** 被误解或被放弃的人相遇 → 一方实际让出有限资源 → 接纳得到具体证据 → 新责任改变双方行动

**具名佐证：4个独立故事族。**

- 《我有六个黄毛爹》`Sc708478c40`：以黄发阿正等人为核心的青年群体用食物、休息与妹妹称谓接纳孩子，外在刻板标签与照料行动相冲突。 定位：P0139、P0210、P0211、P0229。
  - P0139 原文节录：“第一层是身份授予。沈家说“不配姓沈”，阿正说“第七个兄弟”，两种话都在决定谁能进入群体，但后一句给夏夏留下能否接受的选择。第二层是资源共享。炒粉、蛋、水、较淡的那份饭不是无限供给，青年们自己也会为加几个蛋拌嘴，因此分享具有可见成本。第三层是生活空间重排。慧子没有只说“别怕”，而是明确谁睡里面、谁睡外边；人物的站位和铺位让安全感可视化。”
  - P0229 原文节录：“阿正并非听到豪门身份后才愿意帮助，可见邀约发生在路边；夏夏也没有凭豪门身份换取优待。她提出读书，把受助从一顿饭改成长期责任；六人用玩笑应对这个沉重要求。夏夏先接受称谓，随后对食物仍有推辞，说明口头加入与身体放松并不同步。编剧用“嘴上说了愿意，动作还不敢要”的间隙承载情绪，直到最后睡着，才让身体替她给出阶段答案。”
- 《姑妈供我成状元，我用一生报她恩第一季》`S9b40213b4b`：姑妈为孩子杀鸡与争取学习，照料有失去未来收入的实际成本。 定位：P0060、P0061、P0062。
  - P0060 原文节录：“女孩醒来后说自己听到了村医的话，潜台词是她又担心成为负担。姑妈岔开话题，端来鸡汤。周向阳背书包出现，立刻问大将军是不是被杀了，并说明它养了两年、每天能下蛋、原本还要留到过年孵小鸡。观众因此同时看见三重成本：家中的食物资产、男孩的情感陪伴和未来的小鸡可能性。姑妈用“养腻了”“省心”掩饰照料动机；青禾问是不是因为自己生病，男孩忍着眼泪让她快喝，真正完成了哥哥角色的主动选择。”
  - P0062 原文节录：“姑妈站在门口听见，没有立刻承诺明天入学。她回屋打开柜子，查看零散的钱。这个无对白的末尾把读书愿望与现实资源相连：观众知道她听见了，也知道困难是什么，但不知道她会怎样解决。第三集完成了读书动机的建立，没有完成入学，更没有完成考试成才。”
- 《小苦瓜回到东北后》`S4fd22765ce`：换衣与保护姐妹让接纳从称谓落到动作，女孩的戒备与误读逐步被照料纠正。 定位：P0351、P0371、P0375、P0376。
  - P0351 原文节录：“为什么有效：不是只说关心，衣物从母亲移到女孩身上完成看得见的照料。”
  - P0376 原文节录：“误读链持续递进：电话→鞋子方言→被母亲碰头→夹菜→黑虫→姐姐骂人，一串误解不是重复一句她怕，而是以不同物件和行动升级。”
- 《清水故事：农家夫妻的红火小日子》`Sdff86d46ac`：询问意愿、保留姓名与离开旧家形成接纳；手续含义和选择受限仍须保留。 定位：P0041、P0042、P0043、P0044、P0045、P0046、P0047、P0048。
  - P0041 原文节录：“清河自报姓名，说明特地来问她愿不愿意。钱氏抢着回答，还强调五两银子不能少。清河不顺着钱氏谈价，继续面向女孩说“我在问你”，并表明林家不强求。这个动作方向很重要：他没有为她再做一次决定，而是把回答的位置交还给她。”
  - P0048 原文节录：“张春燕注意她衣薄，准备拿旧衣；桂香准备带她看住处，又顾虑照顾清河与孩子还小之间的不便。清河在哥哥背上提出屋里放杂物的小间可以收拾出来，春燕接下整理任务。三集停在晚秋与桂香对视、表情放松之处。小间尚未展示，衣物尚未拿到，不能把口头安排写成已经入住与换装；但家人愿意分担的关系已经成立。”

**边界／反例：** 已发生的食物共享与仅提出的入学、居住安排要分开，不等于升学、暴富或全家和解。缺少选择权的照护关系不能直接当成圆满。

**新组合扩展（原创，未获市场验证）：** 抽掉原作人物与物件，可换成夜班公交维修组与流浪少女：女孩决定用修复技能换住宿，双方各保留拒绝权。

**三路线的落场差异：** 仿真人：让食/让工位的微行动；超创：反常照料群体形成系列；动漫：资源状态直观可见。

## DP02 稀缺生计＋信息或移动异能＋劳动＋交易障碍

**因果链：** 家庭缺口明确 → 能力补一个生产条件 → 角色执行劳动 → 市场和债务给出第二道阻力

**具名佐证：4个独立故事族。**

- 《奶爸赶海：听懂兽语后翻身做渔王》`Sc01893a9cf`：饥饿迫使行动，水獭线索后仍需划船与捕捞。 定位：P0078、P0083、P0086。
  - P0078 原文节录：“林海感谢张大妈照看孩子，承认这几天心力交瘁。她离开后，女儿大宝蹲在父亲腿边，抱着裤腿说自己饿。林海双手抹脸，安排大宝带小宝进屋避风，自己去海边找食物，并保证不让他们饿肚子。家庭关系通过牵手进屋与父亲离开屋前得到落实。”
  - P0086 原文节录：“水獭报告螃蟹已经入笼，同时提醒退潮后笼子会卡入礁缝。林海拉绳，水獭在绳边协助，装满蟹的笼子出水。蟹被倒到船上，与鱼共同构成肉眼可见的回报。最后，林海希望把小船装满值钱海货，水獭承诺以后每次出海都跟着他。”
- 《我家后山藏真龙》`S6f21495d08`：新海域、控水与鱼获估价衔接，但估价和收入不能混同。 定位：P0080、P0130、P0423、P0550。
  - P0080 原文节录：“第三集先兑现捕获。大鱼躲开陈江伸出的手，他没有直接追着乱抓，而是调动水流形成围困，使鱼的逃逸空间收紧，最终抱住它。他把首次下海的收获与“荒山能让我翻身”联系起来。岸上两位渔民还在担心他迟迟不回来；陈江借水势带鱼上岸，旁人由担心转为惊讶，先说大黄鱼，再确认金黄外形、发红鱼鳍、活鱼与大尺寸，又注意到网兜里的大鲍鱼。他没有透露龙珠，只把成果归给运气。渔民建议趁酒店采购在场，赶紧去码头收货处。”
  - P0550 原文节录：“第五，外部评价让价值有递进证据。渔民说明大且活，年长识货者说明稀有，采购者用报价表明愿意争，许之夏用更高价兑现重品质的介绍。这四种功能不能全改成同一句“太厉害了”，否则人物再多也没有信息增量。”
- 《海兽认我当大哥，我在远海当船王》`S9948906b2e`：鳄鱼代船驮行并协助赶蟹，主角用网捕捞，称重收入与抵押期限保留现实压力。 定位：P0082、P0084、P0085、P0086、P0087、P0088、P0089、P0090。
  - P0082 原文节录：“回报分两次检验：先驮人快速出海，证明它能取代船的一项能力；再带到普通船进不来的礁区，证明它还能打开独占性资源。第一集结束在看见青蟹和锦绣龙虾、估算价值，尚未把想象中的财富当成实际收入。”
  - P0090 原文节录：“周玉兰亲自到后屋，带来县城酒楼明晚前要大鲍鱼的生意，要求个头大、鲜活无伤，并说至少能赚一万元。这里是一笔未来订单机会，而非已支付款项。她选择汪莽的原因与第一集礁区能力呼应：别人进不了深礁，他能骑鳄去。父母帮他准备网和饭，却仍要求天黑前回来。结尾把“更大订单”“家庭期望”“安全限制”装进同一个出发动作。”
- 《父爱如山，从落魄打渔开始致富》`Sba3176295f`：已有鱼获仍受销售阻碍，生产成果不自动消除交易权力。 定位：P0188、P0208。
  - P0188 原文节录：“张扬带孩子到礁石水坑边，反派与村民跟来围观。他削尖木棍，利用透视与龙血力量刺中巨鱼。陈怀宇扬言若他真能抓到鱼便把水坑喝了，沈丽娜宣称离婚是最正确决定；巨鱼显现后，两人的话立即受到事实反驳。沈丽娜又表示交出鱼就原谅张扬、回去过日子，被张扬拒绝。她转向女儿用糖诱哄，女儿不肯，沈丽娜扬手，被张扬制止并跌坐在礁石上。张扬邀请围观者报价，价格被喊到六十五万。沈丽娜愤恨父女可能翻身，陈怀宇威胁一句话就能让鱼一文不值，第三集在成交前结束。”
  - P0208 原文节录：“需要特别区分两种“证明”。巨鱼证明张扬此刻能捕到有价值的东西，却不能替代海上事件的证词核验，也没有自动推翻协议的全部主张。短剧把这些冲突挤在同一组反派身上，观众很容易将爽感当作全部问题已经解决，学习者则应保留不同问题各自的结账时刻。”

**边界／反例：** 捕获、估价、成交、拿到钱、还清债是五种状态。不得由“价值多少”直接补成现金到账。

**新组合扩展（原创，未获市场验证）：** 把异能限定成识别废弃零件剩余寿命；女主仍需拆修、证明质量、找到买家，最初只挣够一天托管费。

**三路线的落场差异：** 仿真人：手上劳动和家庭资源；动漫：能力输入输出；超创：异常职业的不同客户。

## DP03 亲密控制＋资源策略＋可执行的边界

**因果链：** 控制落到钱、住处或手续 → 主角改变信息/居住/资源分配 → 对方策略升级 → 新边界接受检验

**具名佐证：4个独立故事族。**

- 《小妹初长成》`S0c3ae07a86`：学费卡与四年居住约定使成长有可见边界。 定位：P0076、P0383。
  - P0076 原文节录：“女孩拿到可用的卡、追问报到材料，并将四年居住承诺写成协议；二哥电脑旧照与寻人奖励另开身份悬念”
  - P0383 原文节录：“初学者可借鉴的可迁移公式：先给一个可见的不公平结果；用人物关系明确谁握有资源；让主角把情绪转成一张清单；每次清单都对应一个物件或手续；在小结果达成后，用尚未解开的身份信息开下一集。不能直接套用的部分是“美貌即价值”“全家脸盲”和“送养/认亲”的极端设定，这些依赖本剧夸张类型语境。”
- 《投资赚到钱，我对家人藏起底牌》`See559be13f`：余额保密、挡住书房与要求还款改变家庭资源的信息分配。 定位：P0022、P0215。
  - P0022 原文节录：“亮点一，观众先知余额，亲人只知50万，信息差构成悬念；二，过去40.2万付出分散成四个生活片段，不只有抽象委屈；三，婚房140万价差和十年付款让偏心有数字；四，保密承诺立即失效，让观众无需解释就能理解信任崩塌；五，书房门框把口头拒绝变成身体站位；六，姐姐第一次夹排骨与400万元请求相邻，礼貌成为戏剧策略；七，琴房童言让大人的愿望更显理所当然；八，追问具体还款时间，比泛泛指责更有推进力。”
  - P0215 原文节录：“先写一张因果卡：过去支付而不被回报，所以主人公控制信息；亲人突破信息边界，所以他阻挡空间进入；借钱请求落地，所以他追问具体时间。不要用身份、热度表格替代这条脉络。”
- 《明珠沈嫚穿书了》`S221681d0a2`：补偿责任与去岛选择互相牵制，离开有成本与前提。 定位：P0079、P0081、P0089。
  - P0079 原文节录：“沈嫚没有顺势要求恢复婚约，而是平静对父亲说明：十几年相处造成的偏心她看得到，但她仍是亲生女儿，婚约原本属于自己；既然父亲和继母帮助满满顶替，将来顾家问责应由他们自行解决，不要牵连她。父亲承诺承担。爷爷再提出具体补偿：拿出存款积蓄，否则就去顾家说明情况。父亲答应去拿。第一集兑现的是责任归属与补偿承诺，钱物尚未真正交到她手里。”
  - P0089 原文节录：“楼下，爷爷整理票和钱，听见招呼后到饭桌。沈嫚明确表示想尽快投奔哥哥，爷爷支持，把攒下的票与退休金交给她，说明已托人购买软铺票，待到手就安排离开，并叮嘱哥哥照顾她。爷爷又请求她帮哥哥留意对象，希望兄妹日后能接自己养老，坦言不想继续留在这个家。她答应努力找对象、找嫂子。张雪梅走近，向她道歉，第三集在这句道歉处结束；道歉内容、诚意与是否获原谅都未揭晓。”
- 《烟火中的尊严》`S919beb17c1`：小额支配权扩大到债务和离婚材料，反抗须经过行动链。 定位：P0057、P0058、P0059、P0060、P0061、P0091。
  - P0057 原文节录：“他改拨朋友电话，请借五万元。对方只问卡号是否换过，随后手机出现“五万元已到账”。这不是主角致富，而是同一个人在两段关系中被怎样对待的对照。他回摊付款，老板把面与绿色瓶装饮品放到面前，还说面可免费续。周一边吃、一边把眼泪压下，终于说七年该结束。回到家，他把每月支出逐一讲清，妻子仍将问题归为他赚得不够。他提出次日九点带身份证去离婚，随后收拾工作用品，离家。”

**边界／反例：** 拒绝、提出条件、提交申请与手续完成分别记录；已有资源的人不能包装成零资源逆袭。

## 怎样形成开发优先级

先比较同一用户目标下的方向。证据充分而因果平庸，不应压过证据较少但开局事件、连续兑现和呈现条件更清楚的原创方向。建议按以下次序给结论：

1. 排除锁卡丢失、规则自相矛盾和核心关系没有选择权的方案。
2. 比较开局事件是否清楚，初期三次发展是否有三种不同回报，代价是否会推动后续。
3. 查看该模式的具名证据、当前组合的全库标签支持以及差异；它们分别回答可迁移性与资料覆盖。
4. 比较制作规模与人物/道具状态负担，给优先开发与小样验证目标。
5. 有同口径市场数据时单列它是否支持推荐；没有时明确这是内容与制作判断。

本文件的原创扩展只是如何迁移的示范，不是固定模板或已经拍过的作品。不得复制原案的人名、专属世界设定与逐场顺序。
