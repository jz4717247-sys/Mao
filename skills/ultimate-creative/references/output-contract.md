# 创意交付合同

交付按当前请求收缩或展开。创意包不是剧本；正文是清晰的提案与事件大纲，禁止分场、连续对白和逐拍表演说明。

## 输出到哪一层

| 请求 | 必须交付 | 不强制附加 |
|---|---|---|
| 给题材/几个方向 | 实质不同的方向卡、比较、推荐与短板 | 每项完整角色传记和全剧大纲 |
| 锁卡抽方向 | 锁卡作用、可变槽位、各方向新的因果、依据边界 | 替用户解除标签、额外世界设定 |
| 明确方向/完整落地 | 下列完整创意包，含结局 | 剧本、分镜、生产资产、写作下一轮 |
| 仅人物/热梗/某段大纲 | 完成本轮指定部分及其对原方案的必要影响 | 重写全部内容 |
| 已有剧本改创意 | 按实际读到范围指出问题，交重构后的方向、人物与大纲 | 替换剧本正文、原稿未提供部分的虚构诊断 |

用户给明确题材但没定一个细节时，以合理假设继续。用户要“几个方向”先给选择；用户要“推荐并落地”由作者选一项完成，不再等待选题许可。

## 方向卡

每个方向至少写这些实质内容，可表格比较并只展开关键项：

- **暂定名与一句故事**：身份、触发、目标、阻力、独特策略、后果齐全。
- **标签组合与作用**：主标签各改变什么，不只是出现在标题。主路线与表现形式分列。
- **主角辨识点**：一项能改变解决问题方式的特色，核心关系双方各想要什么。
- **概念入口**：开场实际发生什么，使读者懂任务与异常；只用事件概述。
- **三次不同发展**：尝试、反馈与阶段回报不同，证明能连载；不是三轮同样打脸。
- **推荐理由与短板**：具体吸引力、同质化风险、规则漏洞与修复办法。
- **依据边界**：资料支持哪部分，哪些是原创；市场数据有日期与口径，无则未知。

匿名比较任务、策略、关系和后果；不同剧名不算不同方向。用户没有要求大胆猎奇时，不强行加入奇幻或巨大奇观。

## 完整创意包

### A. 选题定位

暂定名、类型、主叙事路线/表现形式、受众情绪承诺、核心标签及作用、完整因果句。说明最值得保留的独特之处，以及它如何让主角必须作选择。

### B. 故事发动机与世界

主角当下要完成什么；阻碍者为何要挡他；怎样不断产生新任务/关系冲突；每次成功留下什么新后果；全剧在哪种状态结束。奇幻核心规则给触发、收益、上限、代价、反制；写实故事用资源、制度、关系与信息边界。只展开实际改变人物行动的设定。

### C. 核心角色与关系

初期通常先展开主角、关键关系人物、对手及必要配角，人数按故事决定。用户要完整16型或指定群像时逐一交齐，不能用“其他人后续补”替代。

| 字段 | 交付内容 |
|---|---|
| 身份与剧情职责 | 年龄段、角色位置，独有的行动作用；不只是“搞笑担当” |
| 目标与私人缘由 | 想拿到/保住什么，为什么在乎，失败真正损失什么 |
| 惯用策略与反差 | 常怎么解题；外在形象/自我认知与行为的矛盾 |
| 资源、弱点与底线 | 控制什么、做不到什么、哪种情况愿意付代价 |
| 长相与造型识别 | 少量稳定可辨的轮廓、脸部或穿着特点，如何参与关系/冲突 |
| 声口与身体习惯 | 口音有则写来源与程度；句长、称呼、回避方式、压力下改变、具体小习惯 |
| 与其他人的关系 | 双方各要什么、彼此误信什么、哪次选择会改变关系 |
| 变化或持续错误 | 开局、转折、终局策略怎样变；喜剧不成长也要有积累后果 |

主角的辨识度同时落在 **行动解法与视听记忆点** 上；不要求靠异形长相或浓口音出彩。角色有独立欲望，不能全是主角的小跟班。详细方法见 [人物设计](humanization.md)。

### D. 口头禅设计

各核心角色可给1条主口头禅，必要时附1条压力变体；沉默型可以没有固定句。每条含 **原创短句、触发情境、隐藏目的、不用的情况、后期如何变化**。

例：一个不肯承认自己怕事的维修师，总说“我先看看，没说我接。”用于试探委托；真正承诺救人时改为“这回我接。”这是原创角色短句与变化规划，不是网络热梗或一场对话。

不要让所有人都结论金句化；口头禅删掉后，目标与策略仍应不同。旧方案锁定句保留；需要改时说明具体问题，不默改已认可内容。

### E. 热梗使用方案

即便没有合适表达，也交代哪些角色可能用、哪些情境零梗。原创口头禅和网络表达分列。

| 字段 | 需要说明 |
|---|---|
| 词句与状态 | 已核语境、仅候选待核、旧库储备或本次原创；不把旧词标成当前爆梗 |
| 使用角色/对象 | 为什么这个角色会知道并这样用，争取什么 |
| 适用节点 | 大纲哪种压力/关系触发，怎样形成错位、掩饰或反馈 |
| 不适用节点 | 哪些关键指令、情绪选择、语言/时代不适合 |
| 普通替代与预算 | 不用梗如何同样表达；重复回收和克制计划 |
| 来源与日期 | URL、来源发布/语境日期、核查日期和取得内容层；待核项不推荐实际使用 |

“最新”必须执行 [查新流程](meme-workflow.md)。数据不足可明确零个适用已核项；仍完成角色语言与检索计划。不能为凑数量把人物写成网络词汇展览。

### F. 全剧大纲

交付可理解的完整故事，而非“前期逆袭，中期升级，后期决战”。至少包括：

1. **开局**：触发事件、初次目标、独特规则第一次被检验及损失。
2. **发展阶段**：每阶段目标、主动尝试、对手调整、得到/失去什么、关系或资源怎样改变。
3. **关键转折**：此前哪件行动引出，为什么迫使主角换策略；不是临时新增秘密。
4. **高潮与结局**：谁作什么选择、付什么代价、怎样回应开局承诺，主要关系如何收束。
5. **伏笔与持续变量**：必要伏笔何时埋与回收，能力/资源/知情变化；只列实际有作用的项。

未指定集数时按故事阶段组织，不默认60集。指定集数和时长时安排阶段/逐集事件，说明容量假设；不宣称已校准对白或成片时长。要求逐集大纲时每集给“目标—尝试/反制—状态变化—回报/新问题”的紧凑描述，仍不写分场与对白。

### G. 开发判断与依据

给明确建议、最弱项及如何用概念复述/匿名事件链/用户读梗概检验；不宣称完成观众测试。依据只列实际采用且相关的解析案例/机制与边界，日本操作是补充类比，原创部分明标。来源可收在简短附注，不把研究日志铺满主提案。

## 文件与结束点

用户要求保存或产物较长时，以 `剧名-创意方案.md` 承载完整内容；资料记录必要时另存。无需制造空目录。用户要 Word 时再导出同文版本并核对；不得把创意包命名为“完整剧本”。

停止于本轮要求的创意层。不得附“完整第一集样章”、场标、角色轮流对白、分镜或下一集自动续写；下一步建议可以简短，但不启动写作。
