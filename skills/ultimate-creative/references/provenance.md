# 资料来源、研究方法与证据边界

本版以2026-10-03本地解析档案为快照。全部461份有效DOCX均建立逐篇语义档案：抖音超创20份、AI仿真人214份、AI动漫227份。完整数量、去重结果和支持名单以 [corpus-statistics.json](corpus-statistics.json) 为准，不能沿用初始52份样本的覆盖口径。

## 到底读了什么

逐篇读取故事梗概、人物目标与关系、机制分析和适用边界等章节，再以至少两处正式还原剧本核对关键行动；每篇记录实际P范围、独有因果概括、3–8个标签、2–5个明确机制和至少一项限制。无概要时读正式剧本，根据需要扩读。

这是全库逐篇章节研读，不是所有字符逐字通读。未列P范围不宣称已读；没有重新观看原片、听审音轨或核验嵌入图片。解析中的还原稿也不自动成为官方剧本。完整文本提取与语义阅读分开记录，不能拿自动提取成功冒充研究完成。

源文档提取6,674,411字符，无提取失败或整篇文本SHA完全相同的副本。628行整理台账包含其他范围与状态，不是628份有效解析。前三集、后续季局部范围、预告和幕后都按正文边界处理。

## 三种数量不能混用

- **文档数**：461，反映本地资料覆盖。
- **独立故事族数**：合并同一系列分季、跨目录和已确认的更名版本，反映跨故事支持；不是官方版权IP认证。同一家族在多个归档类别可各计一次，全库只计一次，因此各类别之和可能大于总数。
- **已编码支持数**：至少有一条具体证据支持某机制或标签的故事族数。每篇只编码最明确的若干项，不是穷尽所有特征，未编码不能判为不存在。因此这些是证据支持下限，不是发生率、热度、爆款概率或因果效应。

20个机制码先由初始案例形成，再以同一协议用于全库核验。标签保留逐篇原始措辞，并映射到48个受控上位标签；映射只扫描已做语义判断的标签，不扫描标题、台账或未读正文。原词与上位标签都可查回，不能偷偷混入旧版更细但非统一的标签计数。

去重另有一项保守处理：两份“穿越60…空间不愁吃喝”姓名和平台ID不同，但宝塔田水、饮水、枸杞移种、九姐送稀粥等连续事件高度近似，按一个相关故事族计支持，不宣称已确认官方同IP，也不互相补写剧情。合并降低证据数，防止重制或同原型故事被当成独立验证。

## 结论怎样得到支持

机制结论须包括：具体事件、作用解释、独立故事支持数、相异案例、适用范围与反例。优先跨不同故事比较；续季用于观察变化，不增加独立票数。单例方法保留为可选创作，不扩成通则。即便某机制支持数很高，也不意味着每部剧必须使用。

原文事件、解析作者解释、作者改编建议、本Skill创作归纳分别处理。报告出现“爆款、留存下降、女性爱看”等语句，不等于本任务拿到了完播、曝光或受众数据。例如《银骸》报告对互动下降原因的解释只能作待检验假说，不能升级为已证实的关系戏因果。

标签组合按同一份档案内的交集计算，之后才按故事族去重。不能把某系列第一季有穿越、第二季有另一特征，拼成两者在同一已核剧情中共同起作用的证据。未映射约束保留unknown，不能默默删去它后报告“完整组合有支持”。

## 市场比较

台账是带日期的历史快照，未在本任务重新核验原平台。只有同平台、同榜、同日可作描述比较；排名、热度、播放、互动、完播、收入不能相互替代。系列多文档同日只算一组，排名以该组中位数展示，保留所有原条目供回查。未编码为正例的组不是确认的无标签组。

`market`默认要求同日至少20个故事、每组至少5个，才显示描述性排名比较。这个门槛不是显著性判断。分析库不是完整随机市场样本，也缺少真正失败对照，不能从排名相关性推出标签效果、当前趋势或爆款率。用户要求“现在/最近”时另查当前官方来源。

## 增量更新

只在用户授权更新Skill时持久修改；日常抽卡和写作结果属于项目，不自动写入Skill或长期记忆。

1. 在源目录之外运行 `python3 scripts/index_corpus.py --source /path/to/解析剧 --output /path/to/工作目录/corpus`。脚本仅抽取和索引，不自动生成语义结论。
2. 按相对路径与SHA识别新增和修改，保留快照。正文变更可能使P编号偏移，必须重新定位引用。
3. 对每份新增资料按相同协议读章节与正式剧本，记范围、证据、限制，不能只增“已学习数量”。
4. 审核故事族归并，保留理由。相似题材或相似标题不足以认定同一故事。
5. 重算支持名单、标签交集和历史队列；重新检查受影响结论与创意方向/大纲验证。语义标签、统计数和文字结论须同时更新。

## 跨故事模式证据

`direction-patterns.md` 与同名 JSON 保存13组因果类比、42次具名案例（跨组去重38个故事族），每组3–4个独立故事支持。它们是从461份档案中选取并回查的解释性对比，不是完整标签组合的普查统计。各段原文节录单独逐字回源核验；仍不自动构成市场验证。

选片信号分层：奖项或提名28、票房8、平台报告4、榜单1、发行代理19。奖项与提名逐条区分；19项发行代理只证明作品发行与官方关注，不证明热度。所有数据是各自历史口径，不相互排序，不外推当前抖音表现。

公开文本研究不等于60部正片观看或逐场结构解析。多数有界解释只覆盖开局或若干分集；53作medium、5作limited、2作high是资料覆盖判断，不是作品质量评级。仅JA12首季逃脱阶段有已核收束，不意味着整个系列最终结局。整季有界结构的转移方法还结合[完整构建方法](story-architecture.md)，不补原作未知终局。

每作保留sources与reading_boundary。人物欲望、矛盾、成本可含分析；事实、解释、原创种子分字段。`world.rules.status`只核rule陈述，成本与日常后果可能是归纳，不能转为现实法律、医学或人群普遍性质。多视角作品还须区分客观事件、叙述顺序与角色所信。

[16项跨作操作](japan-operations.json)各有3—4独立故事族支持，51次案例使用、跨操作去重40作；分类另有动画10、日剧8、电影8条归纳，合计26条。它们相互重叠，不是42次独立有效性实验，更不能拿60为每条窄方法背书。操作支持是具名类比、非穷尽编码、非完整标签交集、非成功概率。原367故事族和新60没有完成逐项跨库去重，不能简单相加；也不能把461文档与60IP称521部精读。

独立复核分两层：全60字段与所有引用关联检查；固定seed随机抽12作（动漫/日剧/电影各4）逐作4项语义回源，共48项，另有定点问题核对。抽核不能冒充全60所有事实外部复验。整合修复JA13实际使用但漏声明的第24话、JF04普遍化沟通规则的层级、JF10权力成本的分析标注。

新增时按同协议核首发年份、续季范围、至少两来源、四维内容、关注口径、结局边界，再审独立故事归并与方法支持。源网页失效记录真实限制，不靠搜索摘要补完整剧情。离线包保留自行概述，避免复制大段官方文案；不收凭证、不依赖私有绝对目录。
