# 爽点账本 V1

用途：把"爽"从一种感觉变成**可拆解、可清点、可核对**的结构件。两个场景：

1. **原创**（轨道 T4 竖屏／T5 网文／T2 横屏／剧集）：设计爽点、排布密度、防止通胀失控与假爽点。
2. **改编**（路径 R／引擎 22）：盘点原著爽点 → 改编后逐条核对是否幸存。**爽点是改编里最容易悄悄丢失的东西**——它不像名场面那样有明确边界，删一个见证者、压一段憋期，爽点就废了，但没人说得出哪里出了错，只会觉得"没原著好看"。

与引擎 13 的关系：爽点是**替代成长的兑现瞬间**。每个爽点必须说清它给观众补偿了哪一种心理缺口，否则只是热闹。

==================================================
一、爽点的物理：六个零件，缺一个就不爽
==================================================

> **憋 → 触发 → 执行 → 见证 → 代价 → 余味**

任何一个爽点都由这六个零件构成。写不出其中某一个，那个位置就是塌陷点。

### 零件 1｜憋期（爽的燃料）

爽感强度 ≈ 憋的强度 × 憋的时长（有上限，见第五部分）。没有憋就没有爽，这是最硬的规律。

**憋的三条硬规则：**

1. **观众必须知道主角"有牌没打"。** 否则是纯受虐，不是憋。读者忍得下去，是因为知道他能反击却在忍；不知道，就是弃剧。
   - ❌ 主角单纯弱小挨打 → ✅ 主角一次都没出手，但观众看见他扫过对方的破绽／看见他手里有那份文件
2. **憋期必须有见证者在场积累。** 后面要打谁的脸，谁就必须在憋期里出现并施压。见证者不在憋期出现，兑现时就没人可打。
3. **憋必须是"发过声但无效"，不是"没发声"。** 主角提过、争过、举报过，被压下去了——这才叫憋。什么都不做的忍耐，观众读作懦弱，会不耐烦。

### 零件 2｜触发点

**触发必须来自对手的动作，不能来自巧合或主角心情。** 对手多踩一脚、揭穿一次、当众羞辱一次——由他亲手把开关按下去，观众才觉得是他自找的。

❌ 主角某天想通了，决定反击。
✅ 对方当着所有人撕了他母亲的照片。

### 零件 3｜执行者（决定爽感等级）

| 执行方式 | 爽感 | 说明 |
|---|---|---|
| 主角自己动手 | 最强 | 掌控感直接兑现 |
| 主角设局、借他人之手 | 强 | 智性爽，但需要观众看懂局 |
| 主角的旧恩人／被他护过的人回来还债 | 强 | 义气兑现，见引擎 13 义气程序 |
| 第三方主持公道（法律、上级） | 中 | 需主角提供了关键证据才成立 |
| 天降外援／对手自己倒霉 | 弱到无效 | **这是假爽点，见第四部分** |

### 零件 4｜见证者（最常被忘、最致命）

**爽点没有见证者，等于没有发生。**

- 打脸必须有**那个瞧不起他的人**在场亲眼看见；
- 翻身必须有**曾经的旁观者**在场重新评价；
- 被认可必须由**他一直想得到认可的那个人**说出口——换别人说，补偿不成立。

三层见证者，越全越爽：
1. **主责见证者**：必须看见的那个人（施压者本人）
2. **群体见证者**：当时看笑话的人（同事、同学、亲戚、直播间）
3. **情感见证者**：主角想保护或想证明给他看的人（母亲、孩子、伙伴）

> 见证者缺席时的补救：让他**事后从别人口中听说**并当场变脸——这是次优解，强度约为在场的六成。

### 零件 5｜代价

**赢得毫无损失的爽是廉价的。** 代价可以是：暴露底牌、失去退路、伤了不该伤的人、动用了不该动的关系、从此被盯上。

代价同时是下一段憋的种子——这是连载能一直爽下去的机制。

### 零件 6｜余味与新代价

爽完立刻切，不解释、不升华（见引擎 7 第 7 条双收、EN-V1 机制 71 button）。然后：**温情或胜利之后，让对手拿到新刀**（骨架 G 结尾砍刀）。

==================================================
二、爽点六型（按心理补偿分类，接引擎 13）
==================================================

分类依据不是情节形态，是**观众获得了什么内在补偿**。同一个情节可以属于不同型，取决于它兑现的是哪种缺口。

| 型 | 补偿的心理缺口 | 兑现动作 | 必要见证者 |
|---|---|---|---|
| **S1 打脸** | 尊严恢复 | 瞧不起你的人当场被证明看错了 | 施压者本人＋当时看笑话的群体 |
| **S2 翻身** | 掌控感、命运可改变的信念 | 位置颠倒，规则改由主角定 | 旧秩序的执行者 |
| **S3 护短** | 安全感、归属 | 为自己人做不划算、不理性的事 | 被护的人＋不理解的旁人 |
| **S4 被认可** | 价值感、被看见 | 一直不认可他的人亲口承认 | 那个特定的人（不可替换） |
| **S5 真相揭露** | 公正、被误解的洗刷 | 隐藏身份或真相当众落地 | 误解他的所有人 |
| **S6 反差兑现** | 被需要感、亲密 | 冷的人为你破例、狠的人对你温柔 | 通常只需两人，群体见证反而减分 |

**用法**：写爽点前先定型，型定了见证者就定了。**S4 被认可最容易写坏**——因为它的见证者不可替换，随便找个人说"你真棒"，补偿不成立。

**复合爽点**：强爽点通常同时兑现两型（如"当众护短"＝S3＋S1）。但不要堆三型以上，观众接不住。

==================================================
三、假爽点七种（读起来像爽点，实际不爽）
==================================================

诊断时逐条排查。出现即改，不要靠加台词补。

### F1. 无见证者
主角赢了，但那个瞧不起他的人不在场。→ 补见证者，或改成事后听说＋当场变脸。

### F2. 对手降智
不是主角变强，是对手突然变蠢、犯低级错误。→ 对手必须全力且合理，输在主角的具体一招上。**反派越强，爽点越强。**

### F3. 天降外援
主角没做什么，有人来救。→ 外援可以来，但必须由主角先前的某个选择召来（他护过的人、他埋过的伏笔）。

### F4. 自说自话
主角发表长篇演说，把道理讲透，众人无反应或齐刷刷点头。→ 爽点是**动作和反应**，不是台词。让对方脸色变、让文件摔在桌上、让群体先起哄后噤声。

### F5. 憋不够
铺垫太短，兑现来得太容易。→ 延长憋期或加深羞辱。判定法：观众看到兑现时如果没有"终于"的感觉，就是憋不够。

### F6. 无代价
赢得毫无损失，主角状态比之前更好。→ 加代价，且代价要在下一段发挥作用。

### F7. 平级重复
第三次打脸和第一次强度一样。→ 见第六部分爽点通胀。

==================================================
四、憋爽比与密度（按媒介）
==================================================

**憋爽比**指憋期时长与兑现时长之比。这是节奏的核心参数，各媒介差异极大。

| 媒介 | 憋爽比参考 | 密度基线 | 备注 |
|---|---|---|---|
| **竖屏短剧** | 3:1 到 5:1 | 每集至少一个小爽；每 3–5 集一个大爽 | 憋超过一集半观众就划走；付费点前的憋可以更狠但必须当集有小兑现 |
| **横屏 AI 短剧** | 2:1 到 3:1 | 单条一个完整闭环 | 单条时长短，憋期压缩，靠信息密度而非时长积累 |
| **网文** | 5:1 到 8:1 | 每章一个小爽点或钩子；每卷一个大爽 | 读者容忍度最高，但每章必须有推进感 |
| **剧集** | 6:1 到 10:1 | 每集一个中爽；每季 3–4 个大爽 | 可长线埋，但每集仍需一个当集兑现 |
| **电影** | 全片 2–3 个 | — | 不用爽点密度衡量，靠情感闭环 |

> 数值是基线不是硬配额。判据永远是：**观众在憋的过程中，是否始终知道兑现会来、且值得等。**

**憋期过长的三个救急阀**（长憋时穿插使用，防弃剧）：
1. **小兑现**：给一个不解决主线的小胜（当场怼回一句、拿到一份证据）
2. **观众特权**：让观众知道一件主角还不知道的事（信息差本身是奖赏）
3. **盟友出现**：有一个人相信他——护短的接收端也是爽点

==================================================
五、爽点通胀与升级曲线
==================================================

第二次爽点若与第一次同强度，观众感受到的是**衰减**而非重复。所以每一次必须在下列维度**至少一维**超过上一次：

1. **对手层级**：小主管 → 部门总监 → 集团董事 → 行业规则本身
2. **见证者规模或层级**：三个同事 → 整个部门 → 全公司直播 → 全行业
3. **代价**：丢面子 → 丢职位 → 丢退路 → 丢一个人
4. **执行难度**：随手 → 设局 → 押上全部 → 牺牲
5. **兑现的公开度**：私下 → 半公开 → 当众 → 被记录传播

**不要五维同时拉满**——那样第三次就无处可去了。长篇的通常做法：前中期主要拉对手层级与见证者规模，后期靠代价与牺牲。

**升级的反向操作（高级写法）**：最后一次爽点**缩小**规模但提高精度——不当众，只有两个人，一句话。前面铺够了，这一下最重。适合结局。

六、原著爽点账本（改编启动时填，引擎 22.2 展开）
==================================================

改编前把原著的爽点全部盘出来。**没盘完不许动笔改。**

    【原著爽点账本｜作品名】
    编号：SD-01
    位置：第 X 章 / 第 X 卷
    型别：S1–S6（可复合）
    补偿的心理缺口：（尊严/掌控/被看见/安全/归属/公正）
    憋期：从第几章开始憋，憋了多长，读者具体憋在哪一件事上
    憋期见证者：谁在场施压
    触发点：对手做了什么把开关按下
    执行者：主角自己/设局/借他人/第三方
    兑现方式：当场还是延迟、公开还是私下、具体动作是什么
    见证者：主责/群体/情感 三层分别是谁
    代价：主角付出了什么
    读者反应证据：（书评区、二创、章末评论里读者实际说了什么——有则记，无则标"未核")
    强度评级：★–★★★★★
    是否原著公认名场面：是/否

**填表要点**：

- **"读者反应证据"是这张表的锚**。凭改编者自己的判断认定哪里爽，经常与读者实际反应不符。有书评、有二创、有反复被引用的段落，才算强证据；没有就标"未核"，不要假装有。
- **强度评级决定改编优先级**：★★★★★ 属于引擎 22.1 的 L1 不可动；★★及以下可以合并或删除，但要在账本里记录去向。
- **复合型爽点拆开记**：一个场面同时是打脸和被认可，两条都要有，因为改编时可能只保住其中一条。

==================================================
七、改编后爽点核对（每集/每场过一遍）
==================================================

逐条对照原著账本，核对下列六项。**任一项"否"，该爽点即判定为丢失或减弱。**

    【爽点存活核对｜SD-XX】
    1. 还在吗？（在/移位/合并/删除）—— 移位到第几集、合并进哪一场、删除的功能落到哪
    2. 憋期够吗？—— 改编后的憋期时长与羞辱强度是否支撑得起这次兑现
    3. 见证者齐吗？—— 主责/群体/情感三层分别是否在场；若缺，补了什么
    4. 执行者对吗？—— 是否仍由主角自己或他的布局完成，没有变成天降外援
    5. 兑现够狠吗？—— 是否仍然当场、公开度是否未被降级、动作是否被削成台词
    6. 代价还在吗？—— 是否变成了无损失的胜利

### 改编中爽点丢失的五种典型方式

**M1 憋期被压缩。** 最高发。小说憋了二十章，剧集压成两集，兑现照搬——观众没憋够，爽不起来，反而觉得主角小题大做。
> 改法：要么按比例保留憋期，要么把兑现的规模同步下调。**憋和爽必须同比例缩放**，只压憋不压爽是最常见的翻车。

**M2 见证者被删。** 配角合并时最常见的隐性损失。原著里三个看笑话的同事合并成一个，打脸的群体见证就塌了。
> 改法：合并配角时，先查这个配角是否在某个爽点里担任见证者。是，则合并后的角色必须继承该职能。

**M3 移到画外。** "后来他成了公司最年轻的总监"——一句旁白吃掉一个爽点。
> 改法：爽点不可用 VO 交代（引擎 8 的 VO 禁止项）。宁可删掉，也不要用旁白兑现。

**M4 稀释到多集。** 一次大爽被拆成三次小爽，每次都不够。
> 改法：拆分只在憋期同步延长时成立。否则合并回一次。

**M5 提前剧透。** 预告片或前情提要把兑现画面放出去，正片播到时观众已无惊喜。
> 改法：预告可以放**憋**，不放**兑现**；放兑现的半帧（对手变脸的表情），不放全过程。

==================================================
九、快速诊断（读者/观众说"不爽"时用）
==================================================

按顺序查，先查前面的：

1. **有没有见证者？**（F1）——最高发，先查这个
2. **憋够了吗？**（F5／M1）——第二高发
3. **是主角赢的，还是对手输的？**（F2／F3）
4. **是演出来的，还是说出来的？**（F4）——查是否被削成台词
5. **有代价吗？**（F6）
6. **比上一次强吗？强在哪一维？**（F7）
7. **补偿的是哪种心理缺口？说不出＝这不是爽点，只是热闹**

> 与弹幕预演（引擎 3）联动：爽点段落**必须能预演出"爽"字型弹幕**（"爽""来了来了""等这一刻很久了"）。预演不出来，回到上面七条查。预演出"就这？"，是憋爽比失衡；预演出"编剧脑子进水"，是 F2 对手降智。

==================================================
附：使用边界
==================================================

本库的分型、零件拆解与诊断顺序是创作方法，可直接使用。第四部分的憋爽比与密度**是基线不是硬配额**——具体项目按题材、平台、受众调整，不得为凑数值而加爽点。

爽点密度高不等于作品好：**爽点是情绪兑现手段，不是目的**。人物、心因与主题仍按引擎 13 与引擎 3 的经典化标准衡量。只有爽点没有人物的作品，观众爽完即弃，形成不了角色资产（引擎 13 第十节）。
